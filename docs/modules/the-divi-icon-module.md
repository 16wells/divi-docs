# The Divi Icon Module

!!! abstract "Quick Reference"
    **What it is:** A module that places a single icon on the page, chosen through the [Icon Manager](../builder/the-icon-manager-in-divi-5.md).
    **Where it lives:** Gray Plus icon inside a Row, then the Icon module (or use search).
    **Key settings:** Icon, Link, and the Design tab's Icon color and size.

## Add the module

1. In the Visual Builder, click the **Green Plus** icon to add a Row to the Section.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Select the **Icon** module, or find it with search.

## Use cases

- **Feature sections:** use icons to stand for services or features so content is easier to scan.
- **Visual lists:** add icons to list items to improve readability and guide the eye.
- **Icon buttons:** combine an icon with a link to draw attention to a call to action.

## Settings

### Content tab

| Setting | Description |
|---|---|
| Icon | The icon to display. Pick from Divi Icons, the Font Awesome pack, or your own collection via the [Icon Manager](../builder/the-icon-manager-in-divi-5.md). |
| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| Order | Position within a Flexbox or Grid layout (see [Flexbox layout](../builder/understanding-divi-s-new-flexbox-layout.md)). |
| [Meta](../options-groups/meta.md) | Label text and a switch to force visibility in the Visual Builder. |

### Design tab

| Setting | Description |
|---|---|
| Icon | Icon color and size. |
| Alignment | Alignment of the icon. |
| [Spacing](../options-groups/spacing.md) | Margin and padding. |
| [Border](../options-groups/border.md) | Border styles. |
| [Box Shadow](../options-groups/box-shadow.md) | Box shadow styles. |
| [Filters](../options-groups/filters.md) | Hue shifts, saturation changes, and blend modes. |
| [Transform](../options-groups/transform.md) | Scaling, rotating, skewing, and translating. |
| [Animation](../options-groups/animation.md) | Entrance animation styles. |

| Setting | Description |
|---|---|
| [Attributes](../options-groups/attributes.md) | CSS ID, reusable classes, and custom HTML attributes. |
| [CSS](../options-groups/css.md) | Custom CSS for the module. |
| HTML | Semantic HTML tag (see [Semantic Elements](../builder/semantic-elements.md)). |
| [Conditions](../options-groups/conditions.md) | Show the module only when set conditions are met. |
| Interactions | Custom interactions such as showing or hiding the icon (see [Interactions](../builder/interactions.md)). |
| [Visibility](../options-groups/visibility.md) | Control on which devices the module appears. |
| [Transitions](../options-groups/transitions.md) | Timing of hover transitions. |
| [Position](../options-groups/position.md) | Placement of the module. |
| [Scroll Effects](../options-groups/scroll-effects.md) | Behavior and transforms while scrolling. |

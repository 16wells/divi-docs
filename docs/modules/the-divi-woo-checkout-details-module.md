# The Divi Woo Checkout Details Module

!!! abstract "Quick Reference"
    **What it is:** The current order's cart summary at checkout: products, quantities, subtotal and total.
    **Where it lives:** WooCommerce folder in the module library; intended for a Theme Builder checkout template.
    **Key setting:** Table, Table Row and Table Cell design groups.

!!! note
    WooCommerce must be installed and active before the Woo Checkout Details module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Checkout Details** to insert it, or find it with the search box.

## Use cases

1. **Branded checkout layout:** Show the order summary in a styled section with consistent fonts and borders.
2. **Two-column checkout:** Put the order summary on one side and the billing and shipping forms on the other.
3. **Promotional checkout page:** Place the module in a highlighted container to reinforce order details during campaigns.

# The Divi Woo Checkout Information Module

!!! abstract "Quick Reference"
    **What it is:** The optional order notes field at checkout, positionable anywhere in your layout.
    **Where it lives:** WooCommerce folder in the module library; intended for a Theme Builder checkout template.
    **Key setting:** Elements: show or hide the module title.

!!! note
    WooCommerce must be installed and active before the Woo Checkout Information module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Checkout Information** to insert it, or find it with the search box.

## Use cases

1. **Delivery notes:** Let customers add delivery preferences or special requests, placed where it suits your layout.
2. **Custom field placement:** Move the notes field out of the default WooCommerce position.
3. **Consistent form styling:** Style the label, input and surrounding section to match the rest of checkout.

## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| et_pb_ab_read_page_{$post_id}{$test_id}($cookie_subject} | Verify whether the current visitor has already spent a certain amount of time reading the page with AB Testing subjects. | 1 year |
| et_pb_ab_read_goal_{$post_id}{$test_id}($cookie_subject} | Verify whether the current visitor has already spent at least 3 seconds reading the goal on the page with AB Testing subjects. | 1 year |
| et_pb_ab_view_goal_{$post_id}{$test_id}($cookie_subject} | Verify whether current visitors have already viewed the goal on the page with AB Testing subjects. | 1 year |
| et_pb_ab_click_goal_{$post_id}{$test_id} | Verify whether current visitors have clicked the goal on the page with AB Testing subjects. | 1 year |
| et_pb_ab_con_goal_{$post_id}{$test_id}($cookie_subject} | Verify whether current visitors have taken specific actions on the modules (AB Testing goals). The actions are:- Already visits the Thank You page and comes from the Shop module- Already sends messages via the Contact Form module- Already subscribed successfully to the newsletter on the Email Optin module- Already submits comment via Comment module | 1 year |
| et_pb_ab_con_short_{$post_id}{$test_id} | To verify whether current visitors already visit a page with shortcode tracking enabled. | - 1 year |

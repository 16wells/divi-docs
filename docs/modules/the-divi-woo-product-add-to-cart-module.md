# The Divi Woo Product Add to Cart Module

!!! abstract "Quick Reference"
    **What it is:** A customizable add-to-cart button with optional quantity field and stock info.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Content group: product and elements.

!!! note
    WooCommerce must be installed and active before the Woo Product Add to Cart module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Product Add to Cart** to insert it, or find it with the search box.

## Use cases

1. **Custom product pages:** Give every product template an Add to Cart button styled to your brand.
2. **Featured products on landing pages:** Let visitors add items to the cart beside product details on promotional pages.
3. **Bundles and upsells:** Insert add-to-cart buttons into custom layouts that showcase bundles or related products.

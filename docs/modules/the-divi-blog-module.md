# The Divi Blog Module

!!! abstract "Quick Reference"
    **What it is:** A grid or list of posts, pages, media, projects, or products in full-width or masonry layouts.
    **Where it lives:** Add it from the module library (Gray Plus icon inside a Row) or search for it by name.
    **Key settings:** Content (what to show), Elements (post meta), Overlay, Image, Title, Meta, Read More, and Pagination text.

## Add the module

1. In the Visual Builder, click the **Green Plus** icon to add a Row to the Section.
2. Click the **Gray Plus** icon inside the Row to open the module library.
3. Find the **Blog** module and click it, or use the search box.

## Use cases

- **Posts by category:** Show posts from chosen categories so visitors find relevant content quickly.
- **Masonry grid:** Present posts in a masonry grid for a modern layout.
- **Featured posts:** Highlight important or popular posts.

## Settings

### Content tab

Choose what content the module pulls in, which meta elements to show, and the link and background.

| Setting | Description |
|---|---|
| Content | Which posts or content types the module displays. |
| Elements | Which post elements appear, such as meta details. |
| Link | Turns the whole Blog module into a link. |
| Background | Background styles for the module. |
| Order | Sets where the module sits in a [Flexbox](../builder/understanding-divi-s-new-flexbox-layout.md) or Grid layout. |
| Meta | A custom label and Visual Builder visibility option for the module. |

### Design tab

Design options for the Blog module.

| Setting | Description |
|---|---|
| Layout | How child elements are arranged: Block, Flex, Grid (default). |
| Overlay | Overlay styles for post images. |
| Image | Styles for featured images. |
| Text | Overall text styles. |
| Title Text | Styles for post titles. |
| Meta Text | Styles for the post meta line. |
| Read More Text | Styles for the Read More button. |
| Pagination Text | Styles for the pagination links. |
| Body Text | Styles for the post excerpt. See [Body Text](../builder/understanding-the-body-text-option-group-in-divi-5.md). |
| Sizing | Width, height, and related sizing for the Blog module. |
| Spacing | Margin and padding around and inside the module. |
| Border | Border and corner styling. |
| Box Shadow | Drop shadow styling. |
| Filters | Hue, saturation, brightness, and blend-mode adjustments. |
| Transform | Scale, rotate, skew, and translate effects. |
| Animation | Entrance animation styles. |

### Advanced tab

Options for fine control over markup, visibility, and behavior.

| Setting | Description |
|---|---|
| Attributes | A CSS ID, reusable CSS classes, or custom HTML attributes, handy for hooking into your child theme's stylesheet or custom CSS. |
| CSS | Custom CSS for fine-tuning the Blog module. |
| HTML | Picks the [semantic HTML tag](../builder/semantic-elements.md) the module outputs. |
| Conditions | Shows or hides the module based on rules, so different visitors see different content. |
| Interactions | Custom [Interactions](../builder/interactions.md), such as showing or hiding the module on a trigger. |
| Visibility | Hides the module on selected device sizes. |
| Transitions | Duration and timing of hover and state transitions. |
| Position | Precise placement of the module on the page. |
| Scroll Effects | How the module moves or changes as the visitor scrolls. |

## Save your work

Press `Cmd + S` (Mac) or `Ctrl + S` (Windows), or use the **Save** and **Exit** buttons in the Visual Builder.

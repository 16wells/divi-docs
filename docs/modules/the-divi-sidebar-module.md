# The Divi Sidebar Module

!!! abstract "Quick Reference"
    **What it is:** Displays a WordPress sidebar and its widgets on any page, post, project, or template.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Sidebar** from the module list (or search for it).
    **Key settings:** Content (choose the sidebar), Sidebar Layout.

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Sidebar module.

## Use cases

- **Blog widgets:** list recent posts, categories, or tags beside content.
- **E-commerce navigation:** add product filters, search, or featured products.
- **Page-specific sidebars:** show schedules, sponsor lists, or resources that fit one page.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Choose which WordPress sidebar to show. Widgets are managed through standard WordPress widget functionality, so updates apply everywhere the sidebar appears.

| Setting | Description |
|---|---|
| Content | The WordPress sidebar the module shows. |
| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| [Loop](../builder/loop-builder.md) | Turns on the Loop Builder. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

|---|---|

| [Text](../options-groups/text.md) | Overall text styles. |
| Sidebar Layout | Whether the border separator sits on the left or right side of the container. |
| [Title Text](../options-groups/title-text.md) | Styles for widget titles. |
| [Body Text](../options-groups/body-text.md) | Styles for widget body text. |
| [Sizing](../options-groups/sizing.md) | Size controls for the Sidebar module. |
| [Spacing](../options-groups/spacing.md) | Margin and padding for the Sidebar module. |
| [Border](../options-groups/border.md) | Border styles for the Sidebar module. |
| [Box Shadow](../options-groups/box-shadow.md) | Box shadow styles for the Sidebar module. |
| [Filters](../options-groups/filters.md) | Hue, saturation, blend mode, and similar filter effects. |
| [Transform](../options-groups/transform.md) | Scale, rotate, skew, and translate effects. |
| [Animation](../options-groups/animation.md) | Entrance animation styles. |

### Advanced tab

The Advanced tab holds the options shared by every module.

| Setting | Description |
|---|---|
| [Attributes](../options-groups/attributes.md) | A CSS ID, reusable CSS classes, and custom HTML attributes. |
| [CSS](../options-groups/css.md) | Custom CSS targeted at the module. |
| [HTML](../builder/semantic-elements.md) | Choose the semantic HTML tag for the module wrapper. |
| [Conditions](../options-groups/conditions.md) | Show or hide the module based on conditions, for personalized content. |
| [Interactions](../builder/interactions.md) | Build interactions, such as showing or hiding the module in response to a trigger. |
| [Visibility](../options-groups/visibility.md) | Show or hide the module per device size. |
| [Transitions](../options-groups/transitions.md) | How long hover and state animations take. |
| [Position](../options-groups/position.md) | Precise placement of the module. |
| [Scroll Effects](../options-groups/scroll-effects.md) | How the module reacts as the visitor scrolls. |

# The Divi Comments Module

!!! abstract "Quick Reference"
    **What it is:** The comments section for a post, with the form and comment list fully styleable and placeable anywhere.
    **Where it lives:** Add it from the module library (Gray Plus icon inside a Row) or search for it by name.
    **Key settings:** Elements (avatar, reply, count, meta), Fields, Form Title, Comment Count, Comment text.

## Add the module

1. In the Visual Builder, click the **Green Plus** icon to add a Row to the Section.
2. Click the **Gray Plus** icon inside the Row to open the module library.
3. Find the **Comments** module and click it, or use the search box.

## Use cases

- **Blog post templates:** Control where the comment section sits and how it looks in custom post templates.
- **Product feedback:** Collect customer reviews and comments on product pages.
- **Event pages:** Let attendees ask questions and discuss updates.

## Settings

### Content tab

Choose which comment elements appear and set the link and background.

| Setting | Description |
|---|---|
| Elements | Shows or hides the author avatar, Reply button, comment count, and comment meta information. |
| Link | Turns the whole Comments module into a link to a page, section, or external URL. |
| Background | Background color, gradient, image, video, pattern, or mask for the Comments module. |
| Loop | Switches on the [Loop](../builder/loop-builder.md) so the module repeats for each item in a query. |
| Order | Sets where the module sits in a [Flexbox](../builder/understanding-divi-s-new-flexbox-layout.md) or Grid layout. |
| Meta | A custom label for the module and an option to force its visibility inside the Visual Builder. |

### Design tab

Design options for the Comments module.

| Setting | Description |
|---|---|
| Layout | How child elements are arranged: Block, Flex (default), Grid. |
| Fields | Styles for the comment form fields. See [Fields](../builder/understanding-the-fields-option-group-in-divi-5.md). |
| Image | Design styles for the avatar image. |
| Text | Overall text styles. |
| Comment Count Text | Styles for the comment count. See [Comment Count Text](../builder/understanding-the-comment-count-text-option-group-in-divi-5.md). |
| Form Title Text | Styles for the form title. See [Form Title Text](../builder/understanding-the-form-title-text-option-group-in-divi-5.md). |
| Meta Text | Styles for each comment's meta line. |
| Comment Text | Styles for the comment body. See [Comment Text](../builder/understanding-the-comment-text-option-group-in-divi-5.md). |
| Button | Design styles for the form button. |
| Sizing | Width, height, and related sizing for the Comments module. |
| Spacing | Margin and padding around and inside the module. |
| Border | Border and corner styling. |
| Box Shadow | Drop shadow styling. |
| Filters | Hue, saturation, brightness, and blend-mode adjustments. |
| Transform | Scale, rotate, skew, and translate effects. |
| Animation | Entrance animation styles. |

### Advanced tab

Options for fine control over markup, visibility, and behavior.

| Setting | Description |
|---|---|
| Attributes | A CSS ID, reusable CSS classes, or custom HTML attributes, handy for hooking into your child theme's stylesheet or custom CSS. |
| CSS | Custom CSS for fine-tuning the Comments module. |
| HTML | Picks the [semantic HTML tag](../builder/semantic-elements.md) the module outputs. |
| Conditions | Shows or hides the module based on rules, so different visitors see different content. |
| Interactions | Custom [Interactions](../builder/interactions.md), such as showing or hiding the module on a trigger. |
| Visibility | Hides the module on selected device sizes. |
| Transitions | Duration and timing of hover and state transitions. |
| Position | Precise placement of the module on the page. |
| Scroll Effects | How the module moves or changes as the visitor scrolls. |

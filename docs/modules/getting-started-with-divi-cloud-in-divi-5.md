# Getting Started with Divi Cloud in Divi 5

!!! abstract "Quick Reference"
    **What it is:** Online storage for Divi designs, tied to your Elegant Themes account and usable on any Divi 5 site you sign in to.
    **Stores:** Page layouts, sections, rows, modules, and code snippets.
    **Limits:** Free for every Elegant Themes member up to 50 items; a Divi Cloud membership removes the cap.
    **Sign in:** Visual Builder → Add Layout icon → Saved Layout or Premade Layout → Sign In To Divi Cloud.

## What Divi Cloud is

Divi Cloud works like Dropbox or iCloud for Divi. Designs saved to it live online instead of on one WordPress install, so they follow you between projects. Before Divi Cloud, moving a saved design to another site meant exporting a JSON file from one Divi Library and importing it into another; Cloud removes that step.

## Local versus Cloud

| | Where it is stored | Available on |
|---|---|---|
| Divi Library (local) | The WordPress site you are working on | That site only |
| Divi Cloud | Online, attached to your Elegant Themes account | Every Divi site you sign in to |

In the Load From Library modal, local and Cloud items appear together, and Cloud items carry a cloud icon. Use the cloud icon next to a local item to move it to the Cloud at any time.

## Storage and billing

- Every Elegant Themes member can use Divi Cloud free, up to 50 saved items.
- A Divi Cloud membership unlocks unlimited storage and extra team-sharing features. It is billed monthly (cancel anytime) or annually (paid up front for 12 months with a 25% discount that lasts as long as you keep the membership).
- If you cancel, your Cloud items are kept for 6 months in case you return. You can also export them to the local Library before canceling.
- Divi Cloud is part of Divi, so you must be an Elegant Themes customer to use it.

## What you can save

- Page layouts
- Sections
- Rows
- Modules
- Code snippets

You can also bulk-import an entire Divi Library into the Cloud, save premade layout packs as favorites, and import layout packs bought from the Divi Marketplace.

## Signing in

1. Open a page in the Visual Builder.
2. Click the **Add Layout** icon in the top left corner to open the Load From Library modal.
3. Click the **Saved Layout** or **Premade Layout** card.
4. Click **Sign In To Divi Cloud** in the top right of the modal.
5. Enter your Elegant Themes account credentials in the pop-up.

The session stays signed in for 30 days. If the button is missing, update Divi 5 to the latest version.

## Managing Cloud items

Once signed in, you can:

- Search by name, category, tag, or location (Cloud only, local only, or both).
- Edit, rename, duplicate, or delete items.
- Recategorize items or assign new tags.
- Restore items from the Cloud Trash.
- Mark favorites with the heart icon.

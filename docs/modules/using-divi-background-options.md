# Using Divi Background Options

!!! abstract "Quick Reference"
    **Where:** Module, column, row, or section settings > Content tab > Background.
    **Types:** Color, gradient, image, video, pattern, and mask.
    **Responsive:** Each type can differ on desktop, tablet, and phone.

Background options give any module, column, row, or section a fully responsive backdrop. See also the [Background option group reference](../options-groups/background.md).

## Open the options

1. Open the settings of the element you want to style.
2. Go to the **Content** tab.
3. Click **Background**.

## Background types

| Type | What it does |
|---|---|
| Color | A solid fill chosen with the color picker, with opacity control. |
| Gradient | Custom gradients with chosen colors, direction, start and end points, and linear or radial style. Works alone or layered. |
| Image | An uploaded or library image with position, size, and repeat settings, plus fixed or parallax scrolling. |
| Video | A background video from an uploaded file or a URL, set up to avoid loading problems on mobile. |
| Pattern | Built-in patterns for texture, adjustable in opacity and size, combinable with other types. |
| Mask | Shapes such as circles, diagonals, and geometric forms that create focal areas or section separation, with color, size, and orientation controls. |

## Layer backgrounds

1. Apply your main background type first, such as a color or image.
2. Add a second type, such as a gradient or pattern, and lower its opacity so the layer beneath shows through.
3. For richer effects, try the blend modes available on images and patterns.

## Set backgrounds per device

Use the device icon beside each background setting to give desktop, tablet, and phone their own styles. This lets you simplify or swap a background on small screens.

## Tips

- Use masks to draw attention to a specific area.
- Keep image and video files small so pages load quickly.
- Avoid stacking so many layers that the design becomes busy.

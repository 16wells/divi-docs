# The Divi Woo Products Module

!!! abstract "Quick Reference"
    **What it is:** A dynamic gallery of WooCommerce products: latest, featured, on sale, best selling, top rated, or by category.
    **Where it lives:** Add it from the module library (Gray Plus icon inside a Row) or search for it by name.
    **Key settings:** Product Type, Product Count, Column Layout, Elements (name, image, price, rating, sale badge).

!!! note
    WooCommerce must be installed and activated before the Woo Products module can be used.

## Add the module

1. In the Visual Builder, click the **Green Plus** icon to add a Row to the Section.
2. Click the **Gray Plus** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder, then find the **Woo Products** module and click it, or use the search box.

## Use cases

- **Landing and sale pages:** Show featured or on-sale products with a chosen number of columns.
- **Best sellers and top rated:** Build social-proof sections from sales or ratings.
- **Category showcases:** Display products from selected categories anywhere on the site.

## Settings

### Content tab

Choose which products appear and how, plus the elements shown for each.

| Setting | Description |
|---|---|
| Product Type | Which products to display: Default (menu ordering + name), Latest Products, Featured Products, Sale Products, Best Selling Products, Top Rated Products, or Product Category. |
| Product Count | How many products the module shows. |
| Column Layout | How many columns the products are arranged in. |
| Order | How the products are ordered. |
| Product Offset Number | How many products to skip from the start. |
| Elements | Toggles for pagination (works with Product Count), name, image, price, rating, and sale badge. |
| Link | Turns the whole Woo Products module into a link. |
| Background | Background styles for the module. |
| Order (Flexbox) | Sets where the module sits in a [Flexbox](../builder/understanding-divi-s-new-flexbox-layout.md) layout. |
| Meta | A custom label and Visual Builder visibility option for the module. |

Featured and sale statuses are set on each product in WooCommerce; see the WooCommerce documentation for how.

### Design tab

Design options for the Woo Products module.

| Setting | Description |
|---|---|
| Overlay | Overlay styles for the product image, including overlay color and icon. |
| Image | Product image styles such as border, box shadow, and spacing. |
| Star Rating | Design styles for product ratings. |
| Sale Badge | Design styles for the sale badge. |
| Text | Styles for the review count text. |
| Title Text | Styles for product titles. |
| Price Text | Styles for the product price. |
| Sale Price Text | Styles for the sale price. |
| Sizing | Width, height, and related sizing for the Woo Products module. |
| Spacing | Margin and padding around and inside the module. |
| Border | Border and corner styling. |
| Box Shadow | Drop shadow styling. |
| Filters | Hue, saturation, brightness, and blend-mode adjustments. |
| Transform | Scale, rotate, skew, and translate effects. |
| Animation | Entrance animation styles. |

### Advanced tab

Options for fine control over markup, visibility, and behavior.

| Setting | Description |
|---|---|
| Attributes | A CSS ID, reusable CSS classes, or custom HTML attributes, handy for hooking into your child theme's stylesheet or custom CSS. |
| CSS | Custom CSS for fine-tuning the Woo Products module. |
| HTML | Picks the [semantic HTML tag](../builder/semantic-elements.md) the module outputs. |
| Conditions | Shows or hides the module based on rules, so different visitors see different content. |
| Interactions | Custom [Interactions](../builder/interactions.md), such as showing or hiding the module on a trigger. |
| Visibility | Hides the module on selected device sizes. |
| Transitions | Duration and timing of hover and state transitions. |
| Position | Precise placement of the module on the page. |
| Scroll Effects | How the module moves or changes as the visitor scrolls. |

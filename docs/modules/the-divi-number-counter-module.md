# The Divi Number Counter Module

!!! abstract "Quick Reference"
    **What it is:** A figure or percentage that animates from zero to your chosen value.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Number Counter** from the module list (or search for it).
    **Key settings:** Text (title and number), Elements (percent sign).

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Number Counter module.

## Use cases

- **Achievements:** show projects completed, happy clients, or awards won to build trust.
- **Business growth:** present sales, visits, or follower numbers.
- **Event metrics:** display attendees, workshops, or sponsors.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

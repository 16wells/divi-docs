# The Divi Filterable Portfolio Module

!!! abstract "Quick Reference"
    **What it is:** A project grid with category filters that visitors click to sort Divi projects dynamically.
    **Where it lives:** Add it from the module library (Gray Plus icon inside a Row) or search for it by name.
    **Key settings:** Content (project count, filter categories), Elements, Overlay, Image, Filter Criteria text.

## Add the module

1. In the Visual Builder, click the **Green Plus** icon to add a Row to the Section.
2. Click the **Gray Plus** icon inside the Row to open the module library.
3. Find the **Filterable Portfolio** module and click it, or use the search box.

## Use cases

- **Design portfolios:** Let visitors filter by branding, web design, or graphic design.
- **Business projects:** Present case studies filtered by industry, type, or year.
- **Photography collections:** Sort images by theme such as nature, portraits, or events.

## Settings

### Content tab

Choose how many projects to show, which categories become filters, and which elements appear.

| Setting | Description |
|---|---|
| Content | The number of projects and the categories used as filters. |
| Elements | Shows or hides each project's title, categories, and pagination. |
| Link | Turns the whole module into a link. |
| Background | Background styles for the module. |
| Meta | A custom label and Visual Builder visibility option for the module. |

### Design tab

Design options for the Filterable Portfolio module.

| Setting | Description |
|---|---|
| Layout | How child elements are arranged: Block, Flex (default), Grid. |
| Overlay | Overlay styles for project images. |
| Image | Styles for featured images. |
| Text | Overall text styles. |
| Title Text | Styles for project titles. |
| Filter Criteria Text | Styles for the category filter links. See [Filter Criteria Text](../builder/understanding-the-filter-criteria-text-option-group-in-divi-5.md). |
| Meta Text | Styles for the project meta line. |
| Pagination Text | Styles for pagination. |
| Sizing | Width, height, and related sizing for the Filterable Portfolio module. |
| Spacing | Margin and padding around and inside the module. |
| Border | Border and corner styling. |
| Box Shadow | Drop shadow styling. |
| Filters | Hue, saturation, brightness, and blend-mode adjustments. |
| Transform | Scale, rotate, skew, and translate effects. |
| Animation | Entrance animation styles. |

### Advanced tab

Options for fine control over markup, visibility, and behavior.

| Setting | Description |
|---|---|
| Attributes | A CSS ID, reusable CSS classes, or custom HTML attributes, handy for hooking into your child theme's stylesheet or custom CSS. |
| CSS | Custom CSS for fine-tuning the Filterable Portfolio module. |
| HTML | Picks the [semantic HTML tag](../builder/semantic-elements.md) the module outputs. |
| Conditions | Shows or hides the module based on rules, so different visitors see different content. |
| Interactions | Custom [Interactions](../builder/interactions.md), such as showing or hiding the module on a trigger. |
| Visibility | Hides the module on selected device sizes. |
| Transitions | Duration and timing of hover and state transitions. |
| Position | Precise placement of the module on the page. |
| Scroll Effects | How the module moves or changes as the visitor scrolls. |

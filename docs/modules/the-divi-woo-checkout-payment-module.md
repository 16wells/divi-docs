# The Divi Woo Checkout Payment Module

!!! abstract "Quick Reference"
    **What it is:** The WooCommerce payment options and Place Order button, placeable anywhere in a Divi layout.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Design tab: radio buttons, tooltip, form notice and button groups.

!!! note
    WooCommerce must be installed and active before the Woo Checkout Payment module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Checkout Payment** to insert it, or find it with the search box.

## Use cases

1. **Two-column checkout:** Put payment beside the billing and shipping fields for a balanced layout.
2. **Sticky payment section:** Keep payment in a sidebar that stays visible while shoppers fill in their details.
3. **Promotional checkout pages:** Position payment under order summaries or offers, with the Place Order button emphasized.

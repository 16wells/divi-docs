## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| Centered |  | place your logo above your navigation menu and center both within the header |
| Centered Inline Logo |  | place the logo in line with your nav menu elements, centered between the links |
| Slide-in |  | The header layout will become vertical, and it will slide in from the left side of the screen |
| Fullscreen |  | Header layout will be displayed full screen. |
| Make Full Width |  | This extends the menu to the full width of the browser window. |
| Hide Logo Image |  | If you want, you can completely hide the logo from your menu here. |
| Menu Height |  | Change the menu height to whatever you want. However, be careful to make your menu height manageable since you could waste valuable real estate on a menu instead of your homepage content. |
| Logo Max Height |  | Increase or decrease the max width percentage of your logo to make it bigger or smaller. |
| Text Size, Letter Spacing, Font, Font Style, Text Color, Active Link Color |  | These options allow you to customize the menu links. |
| Background Color |  | This allows you to change the background color of your primary menu. |
| Dropdown Menu Settings |  | The dropdown menu doesn’t have to inherit the style of the main menu. Here, you can create a unique design for your dropdown menu. You can even add custom animation when displaying the dropdown menu. |

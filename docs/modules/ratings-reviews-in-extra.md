### General

| Setting | Type | Description |
|---------|------|-------------|
| Product Ratings |  | TheProduct Reviewcan be added to any post. You will notice a box labeled Review Box Contents when creating a new post. | Breakdown |  | Breakdowns are the components that make up the overall rating. |
| Title |  | This is the title text describing the breakdown. |

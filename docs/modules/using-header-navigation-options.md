## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| WordPress Dashboard |  | board→Appearances→Customizelink or go toWordPress Dashboard → Divi → Theme Customizer. |
| Header Style |  | You can choose between several header styles:Default: The logo will be aligned to the left, and your menu will be aligned to the right.Centered: Center both the logo and the menu, placing the logo on topCentered Inline Logo: The logo and menu items will be added to the same line with your logo placed directly in the center.Slide In: Create a hamburger menu icon in the top right-hand corner of the page. When clicked, that menu slides in from the rightFullscreen: Create a hamburger icon in the top right-hand corner. When clicked, a fullscreen overlay menu will appear. |
| Default |  | The logo will be aligned to the left, and your menu will be aligned to the right. |
| Centered |  | Center both the logo and the menu, placing the logo on top |
| Centered Inline Logo |  | The logo and menu items will be added to the same line with your logo placed directly in the center. |
| Slide In |  | Create a hamburger menu icon in the top right-hand corner of the page. When clicked, that menu slides in from the right |
| Fullscreen |  | Create a hamburger icon in the top right-hand corner. When clicked, a fullscreen overlay menu will appear. |
| Enable Vertical Navigation |  | The vertical navigation settings will change the orientation of our header and navigation bars. You can choose to place the header:On the top,On the side of your page.Enabling the Vertical Navigation setting will change your header to the vertical style, displaying your logo and menu to the left of the page. |
| Hide Navigation Until Scroll |  | TheHide Navigation Until Scrollsetting makes it so that your primary and secondary navigation bars will be invisible until a user begins to scroll down the page. |
| Show Social Icons |  | If you have defined social profiles, you can display these in your header. This option will toggle the social icons on and off. Social icons, when enabled, will appear in the secondary navigation area. |
| Show Search Icon |  | You can also toggle the search icon on and off. If you prefer to avoid allowing visitors to search your website or are simply trying to reduce clutter in your header, then the search icon can be turned off using this setting. |
| Phone Number |  | Within the header, you can place contact information. Filling out the phone number field will display the defined phone number inside the secondary navigation bar. |
| Email |  | Within the header, you can place contact information. Filling out the Email field will display the defined email address inside the secondary navigation bar. |

# The Divi Woo Cart Totals Module

!!! abstract "Quick Reference"
    **What it is:** Shows the cart subtotal, shipping options, fees and final total.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Design tab table, field and button groups.

!!! note
    WooCommerce must be installed and active before the Woo Cart Totals module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Cart Totals** to insert it, or find it with the search box.

## Use cases

1. **Custom cart templates:** Swap the default cart totals for a version that matches your store design.
2. **Checkout reminder sections:** Keep order totals visible at the top or bottom of the checkout page.
3. **Promotional landing pages:** Pair it with Woo Cart Products for bundle or upsell pages that show updated totals.

# The Divi Post Slider Module

!!! abstract "Quick Reference"
    **What it is:** A slider that turns blog posts into slides, in fixed-width or fullwidth layouts, with optional parallax or video backgrounds.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Post Slider** from the module list (or search for it).
    **Key settings:** Content (count, categories, order), Elements, Featured Image, Navigation.

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Post Slider module.

## Use cases

- **Recent posts:** put your latest articles in a slider on the home page.
- **Popular posts:** feature your most-read or trending content.
- **Category sliders:** promote posts from one category, such as news or tutorials.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Pick which posts appear and what each slide shows. Slides can advance automatically or by manual navigation.

| Setting | Description |
|---|---|
| Content | Number of posts, source categories, Read More button text, and sort method. |
| [Elements](../options-groups/elements.md) | Shows or hides navigation arrows, bullet navigation, the Read More button, and post meta. |
| Featured Image | Shows or hides each post's featured image and sets its placement. |
| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

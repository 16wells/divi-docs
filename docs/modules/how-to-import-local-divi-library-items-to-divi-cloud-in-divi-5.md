# How to Import Local Divi Library Items to Divi Cloud in Divi 5

!!! abstract "Quick Reference"
    **Why:** Local Library items exist only on the site they were saved to; Divi Cloud items are available on every Divi site signed in to your Elegant Themes account.
    **Prerequisite:** Sign in to Divi Cloud from inside the Visual Builder first.
    **Limit:** Free Divi Cloud accounts hold 50 items; a Divi Cloud membership removes the limit.
    **Shortcut:** Right-click a local item and choose **Move to Divi Cloud**.

## Before you begin

- Sign in to Divi Cloud from the Visual Builder before starting.
- If your Library has more than 50 items and you are on a free account, the transfer may not include everything.

## Move a page layout to Divi Cloud

1. Open any page in the Visual Builder.
2. Click the **Add Layout** icon in the left sidebar.
3. Click the **Premade Layout** or **Saved Layout** card.
4. Hover over an item that does not show the blue cloud icon.
5. Click the gray cloud icon.

## Move a section, row, or module to Divi Cloud

1. Open any page in the Visual Builder.
2. Open the insert modal by clicking Add Section, Add Row, or the Add button for a module.
3. Switch to the **Add From Library** tab.
4. Hover over an item that does not show the blue cloud icon.
5. Click the gray cloud icon.

The selected element is transferred to your Divi Cloud account.

!!! tip
    You can also right-click a local Library item (page layout, section, row, or module) and choose **Move to Divi Cloud** from the context menu.

## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| Components Manager |  | nent on your page, or open one from theComponents Manager. |
| Gray Plus |  | Gray Plusiconinside one of the component's columns or Group modules, which will show the list of available Divi modules. |
| Slot module |  | t moduleat the top of the list, next to the Group module, and click on it to load it. |
| Add the Slot to the component once. |  | It becomes part of the shared component, in the same position on every page. |
| Fill it on each page. |  | On each page that uses the component, click theGray Plusicon inside the Slot and add the modules you need. That content is saved with the page, not with the component. |
| Keep editing the component as usual. |  | When you edit and save the component, the content inside each page's Slot is left alone. Every page keeps its own. |
| Empty Slots are invisible to visitors. |  | If you don't add anything to a Slot on a page, it outputs nothing on the front end. |
| Content can move into a Slot, but not out to the component. |  | You can drag content from the page into a Slot, or from a Slot out to the page. You can't drag Slot content into the shared part of the component. |
| Duplicating a Slot gives you an empty one. |  | When you duplicate a Slot while editing the component, the copy starts empty. |
| Components inside a Slot stay components. |  | If you add a component inside a Slot, it stays linked to its own original. |
| Removing a Slot from the component removes its content everywhere. |  | If you delete a Slot from the component, the content that pages had placed in it stops showing. |
| Shared card, different content |  | Build a card component with a border, background, and padding, and put a Slot inside it. Each page fills the card with its own image, text, and buttons, while the card's style stays consistent everywhere. |
| Hero section with a page-specific message |  | Save a hero section as a component with the background and layout you want, and add a Slot where the headline and buttons go. Each page gets its own message inside the same hero. |
| Sidebar or call-to-action band |  | Keep the heading of a band in sync across the site, and use a Slot below it for content that changes from page to page, such as a signup form on one page and a contact button on another. |

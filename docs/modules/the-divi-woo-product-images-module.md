# The Divi Woo Product Images Module

!!! abstract "Quick Reference"
    **What it is:** Shows a product's images outside the default WooCommerce layout.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Position the product image anywhere in your design and control its size, alignment, and style to build product pages that put visuals first.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Images**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Custom product templates:** keep image styling consistent across all product pages.
- **Promotional landing pages:** pair the image with custom text and calls to action.
- **Minimalist product displays:** make a single featured image the focal point.

## Settings

### Content tab

| Setting | Description |
|---|---|
| Content | Choose the product whose images are shown. |
| Elements | Toggle **Show Featured Image**, **Show Gallery Images** (the thumbnails), and **Show Sale Badge** (only appears if the product has a sale price). |
| [Link](../options-groups/link.md) | Makes the whole Woo Product Images module clickable, pointing to a page, section, or external URL. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| Loop | Enable the loop builder for this module (see [Loop Builder](../builder/loop-builder.md)). |
| Order | Position of the module within a Flexbox or Grid layout (see [Flexbox layout](../builder/understanding-divi-s-new-flexbox-layout.md)). |
| [Meta](../options-groups/meta.md) | Label text for the module and a switch to force its visibility inside the Visual Builder. |

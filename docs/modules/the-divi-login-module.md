# The Divi Login Module

!!! abstract "Quick Reference"
    **What it is:** A login form for members-only content, gated resources, and downloads.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Login** from the module list (or search for it).
    **Key settings:** Text, Redirect, Fields, Button.

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Login module.

## Use cases

- **Members-only access:** restrict pages or sections to registered users.
- **Branded login pages:** build a login form that matches your design instead of the default WordPress screen.
- **Header login:** put a compact form in the header so people can sign in from any page.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Set the form title and body text, and choose what happens after login.

| Setting | Description |
|---|---|
| [Text](../options-groups/text.md) | The form title and body text. |
| Redirect | Where visitors go after a successful login. |
| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Elements](../options-groups/elements.md) | Adds nested modules, such as the Link module. |
| [Background](../options-groups/background.md) | Background styles for the Login module. |
| [Loop](../builder/loop-builder.md) | Turns on the Loop Builder. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

# The Divi Image Module

!!! abstract "Quick Reference"
    **What it is:** Displays one image, with optional link or lightbox, plus the usual filter, shadow, and animation styling.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Image** from the module list (or search for it).
    **Key settings:** Image file, Link (including Open in Lightbox), Overlay, Alignment.

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Image module.

## Use cases

- **Featured images:** highlight product shots or promo banners on a home or landing page.
- **Visual breaks:** place images between text sections to improve page flow.
- **Hero sections:** use a large, high-quality image to set the tone at the top of a page.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Choose the image, set a link, and style the background.

| Setting | Description |
|---|---|
| [Image](../options-groups/image.md) | The image file, picked from the Media Library or uploaded. |
| [Link](../options-groups/link.md) | Makes the image clickable, or opens it in a lightbox window. |
| [Elements](../options-groups/elements.md) | Adds nested elements. See [Nested Modules](../builder/nested-modules.md). |
| [Background](../options-groups/background.md) | Background styles for the Image module. |
| [Loop](../builder/loop-builder.md) | Turns on the Loop Builder. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

### Design tab

| Setting | Description |
|---|---|
| Alignment | Aligns the image within its container. |
| [Overlay](../options-groups/overlay.md) | Overlay styles for the image. Applies when **Open in Lightbox** is enabled under Content > Link. |
| [Sizing](../options-groups/sizing.md) | Size controls for the module. |
| [Spacing](../options-groups/spacing.md) | Margin and padding. |
| [Border](../options-groups/border.md) | Border styles. |
| [Box Shadow](../options-groups/box-shadow.md) | Box shadow styles. |
| [Filters](../options-groups/filters.md) | Hue, saturation, blend mode, and similar filters. |
| [Transform](../options-groups/transform.md) | Scale, rotate, skew, and translate. |
| [Animation](../options-groups/animation.md) | Entrance animation styles. |

### Advanced tab

The Advanced tab holds the options shared by every module.

| Setting | Description |
|---|---|
| [Attributes](../options-groups/attributes.md) | A CSS ID, reusable CSS classes, and custom HTML attributes. |
| [CSS](../options-groups/css.md) | Custom CSS targeted at the module. |
| [HTML](../builder/semantic-elements.md) | Choose the semantic HTML tag for the module wrapper. |
| [Conditions](../options-groups/conditions.md) | Show or hide the module based on conditions, for personalized content. |
| [Interactions](../builder/interactions.md) | Build interactions, such as showing or hiding the module in response to a trigger. |
| [Visibility](../options-groups/visibility.md) | Show or hide the module per device size. |
| [Transitions](../options-groups/transitions.md) | How long hover and state animations take. |
| [Position](../options-groups/position.md) | Precise placement of the module. |
| [Scroll Effects](../options-groups/scroll-effects.md) | How the module reacts as the visitor scrolls. |

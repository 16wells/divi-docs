## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| Enhanced Security |  | Protects against password theft, phishing, and brute force attacks. |
| Prevent Unauthorized Access |  | Even if someone knows your password, they would still need the second factor to log in. |
| Compliance |  | For those managing business or sensitive data, 2FA might be necessary to meet certain compliance standards. |
| Log In |  | Use your Elegant Themes account credentials to log into the Members Area. |
| Navigate to Security Settings |  | Go to Account Details > Security, or use this direct link:https://www.elegantthemes.com/members-area/account-security/ |
| Activate 2FA |  | Look for an option labeled "Enable Two Factor Authentication". Click to start the setup process.​ |
| Open Your Authenticator App |  | Popular options include:Google Authenticator- Available on both Android and iOS.Authy- Known for its cloud backup feature, available for both mobile and desktop.Microsoft Authenticator- Offers secure sign-in for Microsoft and non-Microsoft accounts.​ |
| Google Authenticator |  | Available on both Android and iOS. |
| Authy |  | Known for its cloud backup feature, available for both mobile and desktop. |
| Microsoft Authenticator |  | Offers secure sign-in for Microsoft and non-Microsoft accounts.​ |
| Scan the QR Code |  | Your Members Area will display a QR code. Use your authenticator app to scan this code. This will automatically add your account to the app, generating unique codes every 30 seconds.​ |
| Enter the Generated Code |  | Type the code shown in your authenticator app into the field provided on the Members Area page to confirm the setup. |
| Bitwarden |  | The open-source password manager, Bitwarden, offers a similar browser-based authentication for free, with the ability to use 2FA across devices:​Install Bitwarden: Download the Bitwarden extension for your browser.Enable 2FA in Bitwarden: Go to your Bitwarden settings, enable 2FA, and follow the prompts to set it up with your Elegant Themes account. |
| Install Bitwarden |  | Download the Bitwarden extension for your browser. |
| Enable 2FA in Bitwarden |  | Go to your Bitwarden settings, enable 2FA, and follow the prompts to set it up with your Elegant Themes account. |
| Store Them Safely |  | Keep them offline or in a secure password manager. |
| Generate New Codes |  | After using one or more recovery codes, or if the list was compromised, it is strongly advised to generate a new list of recovery codes from your account settings. |

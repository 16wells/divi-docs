# Using Divi Border Options

!!! abstract "Quick Reference"
    **Where:** Module settings > Design tab > Border.
    **Controls:** Rounded corners, which sides get a border, width, color, and style.
    **Gotcha:** A border must be at least 1px wide to show.

The Border option group puts an outline around a module and can round its corners. See also the [Border option group reference](../options-groups/border.md).

## Open the options

1. Click the module or its Gear icon to open its settings.
2. Go to the **Design** tab and open **Border**.

## Settings

| Setting | Description |
|---|---|
| Rounded Corners | Corner radius. Corners are linked by default so all four match; click the chainlink icon to unlink them and set each corner separately. |
| Border Styles | Apply the border to all sides together or to individual sides (top, right, bottom, left). |
| Border Width | How thick the border is, set with the slider or a typed value. It needs to be at least 1px to appear. |
| Border Color | Pick from the site palette or use the color picker. |
| Border Style | Solid, dashed, dotted, double, groove, ridge, inset, outset, or none (which removes the border). |

## Tips

- Use a border to set one module apart from its neighbors.
- Thin borders in softer colors tend to look cleaner.
- Dashed or dotted styles suit decorative uses.
- Rounded corners soften a module's look.

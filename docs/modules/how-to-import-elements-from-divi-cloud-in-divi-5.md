# How to Import Elements From Divi Cloud in Divi 5

!!! abstract "Quick Reference"
    **What it is:** Bringing items saved in Divi Cloud (page layouts, sections, rows, modules, and code snippets) into the page you are editing.
    **How:** Use the same **Load From Library** modal as local Library items, and check **My Divi Cloud** under **Locations** to show only Cloud items.
    **Prerequisite:** You must be signed in to Divi Cloud from inside the Visual Builder.

Importing is contextual. Clicking **Add Section** lists only sections, even if your Cloud also holds layouts, rows, and modules. The same is true for **Add Row** and **Add Module**. To see every item type together, click the **Add Layout** icon in the left sidebar.

## Import a page layout

1. Open the page in the Visual Builder.
2. Click the **Add Layout** icon in the left sidebar.
3. Choose **Saved Layout** to open the Load From Library modal.
4. Optionally check **My Divi Cloud** under **Locations**, and narrow the list with search, **Categories**, or **Tags**.
5. Click the layout you want.
6. Click **Use This Layout**.

!!! warning
    To keep existing page content, make sure **Replace Existing Content** is unchecked before clicking **Use This Layout**. Otherwise the imported layout replaces what is on the page.

## Import a section, row, or module

1. Open the page in the Visual Builder.
2. Click **Add Section**, **Add Row**, or **Add Module**, depending on what you want.
3. Open the **Add From Library** tab.
4. Optionally check **My Divi Cloud** under **Locations**, and narrow the list with search, **Categories**, or **Tags**.
5. Click the item.
6. Click **Use This Section**, **Use This Row**, or **Use This Module**.

Rows can only be imported inside sections, and modules only inside rows, because the **Add Row** and **Add Module** icons appear only in those contexts.

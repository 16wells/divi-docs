# The Divi Woo Product Description Module

!!! abstract "Quick Reference"
    **What it is:** Shows a product's short or long description outside the default WooCommerce layout.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Place the description wherever it suits your product template or landing page, and style it to match your design.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Description**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Custom product templates:** show the long description in a styled section for detailed product information.
- **Quick view sections:** use the short description in compact layouts for a brief overview.
- **Landing pages:** put the short description next to calls to action to highlight benefits.

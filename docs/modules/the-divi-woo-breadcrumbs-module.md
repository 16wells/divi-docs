# The Divi Woo Breadcrumbs Module

!!! abstract "Quick Reference"
    **What it is:** A WooCommerce breadcrumb trail for navigating back through product categories.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Content group: product, home text, home link and separator.

!!! note
    WooCommerce must be installed and active before the Woo Breadcrumbs module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Breadcrumbs** to insert it, or find it with the search box.

## Use cases

1. **Product page navigation:** Let shoppers jump from a product to its parent category without using the main menu.
2. **Multi-level category stores:** Show where a shopper sits in a deep hierarchy such as Clothing, Men, Jackets.
3. **SEO and usability:** Use breadcrumbs sitewide to make the content hierarchy obvious to visitors and search engines.

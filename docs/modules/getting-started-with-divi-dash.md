## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| The Website tab |  | allows you toadd new websites, search, and filter through existing websites. |
| The Updates tab |  | displays a list of all websites with updates available (including updates for currently inactive plugins). |
| The Themes tab |  | displays a list of installed themes across all of the websites added to the Divi Dash. For each theme, you can see how many websites a theme has been installed to, how many updates are available, and on which websites a particular theme has been installed. |
| The Plugins tab |  | offers a list of all the installed plugins (this includes plugins that are active and inactive) on all the Divi Dash websites |
| The Clients tab |  | displays a list of all the clients and the websites to which they are assigned. For each client, you can see the number of sites to which it has been assigned, the name of the client, and his email address |
| The History tab |  | shows a complete history, including the type of action performed: updates, activations, deletions, optimization actions, and more. |
| The Permission tab |  | allows you to manage your team throughDivi Teamsand set the permissions for each team member. |
| Blue Number |  | ber(16) indicates the total number of WordPress sites that were added to your Divi Dash |
| Purple number |  | ber(8) indicates the total number of WordPress sites that are using Divi Theme |
| Turquoise Blue number |  | ber(6) indicates the total number of WordPress sites for which updates are available. |

## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| Keyboard Navigation |  | One of the key features is the ability to make Divi elements focusable, allowing users to navigate your site using just the keyboard. This is crucial for those who cannot use a mouse, ensuring they can interact with your site's menus and content through the "Tab" key. |
| ARIA Support |  | By adding Accessible Rich Internet Applications (ARIA) attributes to Divi modules, you enhance how assistive technologies like screen readers interpret your site's interactive elements. This feature helps in providing context to users, making navigation and interaction intuitive. |
| Visual Focus Indicators |  | The plugin adds visible outlines to elements when they receive focus, improving the experience for keyboard users by clearly indicating which element is currently selected. |
| Alt Text Management |  | Divi Assistant also includes options within its Media Helper to manage and apply alt text to images, which is essential for describing images to users who rely on screen readers. |
| Decorative Icon Accessibility |  | You can set icons as ARIA hidden if they are purely decorative, ensuring they do not confuse users of assistive technologies. |
| Accessibility Sidebar |  | allows website visitors to customize your Divi website appearance for improved accessibility based on their individual needs and preferences. |
| Accessibility Attributes |  | lets you add essential attributes to Divi sections, columns, rows, modules, and individual HTML elements to improve website accessibility for visitors who rely on assistive technologies. |
| Accessibility Tweaks |  | automatic adjustments to your Divi website’s modules and HTML elements to improve navigation and accessibility for all website visitors.​ |

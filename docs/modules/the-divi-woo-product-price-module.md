# The Divi Woo Product Price Module

!!! abstract "Quick Reference"
    **What it is:** Shows a product's price outside the default WooCommerce layout.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Place the price in any template or landing page and style it to match your brand.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Price**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Custom product templates:** put the price under the title for a consistent look.
- **Sales landing pages:** pair the price with promotional text and calls to action.
- **Upsell sections:** show prices next to cross-sell or upsell items.

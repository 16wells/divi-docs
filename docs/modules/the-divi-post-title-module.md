# The Divi Post Title Module

!!! abstract "Quick Reference"
    **What it is:** Shows the current post's title, meta text, and featured image; built for dynamic templates in the Theme Builder.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Post Title** from the module list (or search for it).
    **Key settings:** Elements (title, meta, author, date, comments, featured image).

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Post Title module.

## Use cases

- **Blog post headers:** show a styled title for every post with consistent design.
- **Dynamic templates:** the right title loads automatically on each post or page in a template.
- **SEO-friendly headers:** pair the title with meta information in a clear layout.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

|---|---|

| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| [Loop](../builder/loop-builder.md) | Turns on the Loop Builder. |

# The Divi Testimonial Module

!!! abstract "Quick Reference"
    **What it is:** A module that presents a customer quote with the author's name, job title, company, and picture.
    **Add it:** Gray Plus icon inside a Row, then pick Testimonial from the module list (or search for it).
    **Settings:** Content, Design, and Advanced tabs.

Use the Testimonial module to put real customer or partner feedback in front of visitors. Each instance holds one quote, an author, and optional image and quote icon.

## Add the Testimonial module

1. When you open the Visual Builder, Divi starts you with a Section.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row to open the module list.
4. Select **Testimonial**, or type its name into the search field.

## Use cases

- **Service and product pages:** back up your claims with client feedback right where people decide.
- **About pages:** show customer satisfaction next to your brand story.
- **Partner endorsements:** feature quotes from collaborators or influencers to strengthen credibility.

## Settings

The module settings open as soon as you add the module. They are split into three tabs.

### Content tab

Text content, the author image, and whether the quote icon appears.

| Setting | Description |
|---|---|
| Text | Author name, job title, company, and the quote text. |
| Image | The author's picture. |
| Elements | Show or hide the quote icon. |
| [Link](../options-groups/link.md) | Make the whole module clickable and send visitors to a page, section, or external URL. |
| [Background](../options-groups/background.md) | Background color, gradient, image, video, pattern, or mask. |
| [Loop](../builder/loop-builder.md) | Turn on the loop builder so the module repeats for each item in a query. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position of the module inside a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | The module's label and whether it stays visible inside the Visual Builder. |

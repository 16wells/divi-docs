# The Divi Portfolio Module

!!! abstract "Quick Reference"
    **What it is:** Displays your WordPress projects in a fullwidth or grid layout.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Portfolio** from the module list (or search for it).
    **Key settings:** Content (count and categories), Elements, Layout (Fullwidth or Grid).

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Portfolio module.

## Use cases

- **Creative work:** show design, photography, or video projects in a clean grid.
- **Case-study galleries:** organize case studies by category.
- **Client projects:** feature completed work with images and descriptions.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Choose how many projects appear and which categories they come from.

| Setting | Description |
|---|---|
| Content | How many projects to show and from which Project categories. |
| [Elements](../options-groups/elements.md) | Shows or hides each project title, the categories, and pagination. |
| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

| [Pagination Text](../options-groups/pagination-text.md) | Styles for the pagination links. |
| [Sizing](../options-groups/sizing.md) | Size controls for the Portfolio module. |
| [Spacing](../options-groups/spacing.md) | Margin and padding for the Portfolio module. |
| [Border](../options-groups/border.md) | Border styles for the Portfolio module. |
| [Box Shadow](../options-groups/box-shadow.md) | Box shadow styles for the Portfolio module. |
| [Filters](../options-groups/filters.md) | Hue, saturation, blend mode, and similar filter effects. |
| [Transform](../options-groups/transform.md) | Scale, rotate, skew, and translate effects. |

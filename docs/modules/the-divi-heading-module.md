# The Divi Heading Module

!!! abstract "Quick Reference"
    **What it is:** Displays customizable heading text.
    **Where it lives:** Divi module library (inside a Row).
    **Key setting:** Heading Text design group, plus the HTML tag setting for semantic level.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Click **Heading** to insert it, or find it with the search box.

## Use cases

1. **Page titles:** Give every page title a consistent look.
2. **Section headers:** Mark off sections so content is easier to scan.
3. **Highlighting key information:** Make an important message or call to action stand out.

# How to Set a Row to Be Fullwidth in Divi 5

!!! abstract "Quick Reference"
    **Default:** A Row is 80% wide with a max width of 1080px.
    **To go fullwidth:** Set **Width** to 100% and **Max Width** to none.
    **Where:** Row settings, Design tab, Sizing.

## Steps

1. Open the Row settings by clicking the **Gear icon** or the Row itself.
2. Go to **Design tab, Sizing**.
3. Set **Width** to **100%**.
4. Set **Max Width** to **none**.

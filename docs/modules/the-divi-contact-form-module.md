# The Divi Contact Form Module

!!! abstract "Quick Reference"
    **What it is:** A form with customizable fields that emails submissions to an address you choose, with spam protection.
    **Where it lives:** Add it from the module library (Gray Plus icon inside a Row) or search for it by name.
    **Key settings:** Form fields, Email and Message Pattern, Redirect, Spam Protection, Fields styles.

## Add the module

1. In the Visual Builder, click the **Green Plus** icon to add a Row to the Section.
2. Click the **Gray Plus** icon inside the Row to open the module library.
3. Find the **Contact Form** module and click it, or use the search box.

## Use cases

- **Client project inquiries:** Add fields such as project type, budget, and timeline.
- **Support requests:** Collect contact details, issue category, and description.
- **Testimonials:** Gather name, email, and testimonial text from customers.

## Settings

### Content tab

Manage the form fields, set where submissions go, and control what happens after sending.

| Setting | Description |
|---|---|
| Elements | Add, edit, or remove form fields (see below), or nest other Divi modules inside the form. |
| Text | The form title, the success message, and the submit button text. |
| Email | The address submissions are sent to, plus the Message Pattern. |
| Redirect | What the form does after a successful submission. |
| Link | Turns the whole Contact Form module into a link. |
| Spam Protection | The type of spam protection used. |
| Background | Background styles for the module. |
| Loop | Switches on the [Loop](../builder/loop-builder.md). |
| Order | Sets where the module sits in a [Flexbox](../builder/understanding-divi-s-new-flexbox-layout.md) or Grid layout. |
| Meta | A custom label and Visual Builder visibility option for the module. |

| Setting | Description |

## Add, edit, and remove form fields

1. Open the module settings (click the module or its Gear icon).
2. **Edit:** click the Pencil icon beside a field.
3. **Add:** in the **Content** tab, click **Add New Field**.
4. **Duplicate:** click the Duplicate icon beside the field.
5. **Remove:** click the Trash icon beside the field.

To control field widths (for example, two fields side by side that stack on smaller screens), see the Elegant Themes article on Contact Form field widths in Divi 5.

## Save your work

Press `Cmd + S` (Mac) or `Ctrl + S` (Windows), or use the **Save** and **Exit** buttons in the Visual Builder.

## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| WordPress |  | PressDashboard→Appearance→Customize→WooCommerce→Product Images: |
| Main Image Width |  | e Width- this is the size of the Product Images displayed on a single product page. |
| Thumbnail Width |  | l Width- this is the width of the Product Image displayed in the Shop Page, Woo Archive Pages and the Woo Products module. |
| Thumbnail Cropping |  | this is used to define a custom cropping that will apply only to the Product Images displayed in the Shop Page, Woo Archive Pages, and Woo Products module. |

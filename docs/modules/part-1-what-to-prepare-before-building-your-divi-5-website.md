# Part 1: What to Prepare Before Building Your Divi 5 Website

!!! abstract "Quick Reference"
    **What it is:** The first part of a 16-part Divi 5 Mastery Course that builds a coworking-business website from a blank WordPress install to launch.
    **Covers:** WordPress and Divi basics, installation, the Divi dashboard, and what to gather before opening the builder.
    **Audience:** Anyone starting fresh, new to WordPress or to Divi.
    **Next:** Part 2, exploring the Divi 5 interface.

## How WordPress and Divi fit together

WordPress is the content management system for pages, posts, media, and settings. A theme sets the site's default look and structure. A page builder adds visual, drag-and-drop design. **Divi is both a theme and a builder**, plus the Theme Builder for templates such as headers, footers, blog post layouts, archives, and 404 pages, so layout, styling, global templates, and responsive design live in one system.

## Install WordPress and Divi

WordPress needs web hosting. Many hosts offer one-click WordPress. Divi Hosting ships with WordPress and Divi pre-installed. Otherwise follow Elegant Themes' guide on installing WordPress.

To install Divi 5:

1. Download the Divi 5 zip from the Elegant Themes Members Area.
2. In WordPress, go to **Appearance > Themes > Add New > Upload Theme**.
3. Upload the zip, click **Install Now**, then **Activate**.
4. Follow the onboarding prompt to connect your Elegant Themes license so updates arrive.

A **Divi** item then appears in the WordPress sidebar.

## The Divi menu

| Item | Purpose |
|---|---|
| Divi Dashboard | Main hub: license status, Divi version, links to create pages, manage templates, or generate a site with Divi Quick Sites (not used in this course). |
| Divi 5 Migrator | Migrates an existing Divi 4 site to Divi 5. |
| Theme Options | Site-wide defaults. See below. |
| Theme Builder | Create and assign global templates (header, footer, blog post, 404, archives). Built in Parts 6 to 8; default templates apply until then. |
| Theme Customizer | Where the basic website design system is set. |
| Role Editor | Controls Visual Builder access for WordPress users. |
| Divi Library | Local library for creating, importing, and managing layouts. |
| Support Center | Tools for you and Elegant Themes support to diagnose problems. |

**Theme Options tabs most useful early on:**

- **General:** site logo and social media URLs, which feed the default header and footer.
- **General > Performance:** enable Dynamic CSS, Dynamic Module Framework, and Critical CSS from the start.
- **Integration:** site-wide tracking scripts; the "Add code to the head" field is most common.
- **Updates:** where your Elegant Themes username and API key are stored.
- The Navigation, Builder, Layout, Ads, and SEO tabs need not be configured before moving on.

## Edit pages with Divi

1. Go to **Pages > Add New** (or **All Pages** to edit one).
2. After titling and saving, click **Edit With Divi** to launch the Visual Builder.

You can also click **Edit With Divi** in the admin bar while viewing any page when logged in.

## Gather materials before you build

- **Brand direction:** a primary color, a secondary or accent, and neutrals (near-black text, near-white background, one or two grays); hex codes ideally. Pick a heading font and a body font; two is enough, and Google Fonts load natively. These become Design Variables in Part 3.
- **A logo:** works on light and dark backgrounds, SVG or high-resolution transparent PNG. A styled text placeholder or Divi's default logo works until the real one is ready.
- **Images and media:** gather more than you think you need and compress before uploading. For the coworking example: workspaces, people collaborating, meeting rooms and offices, building exteriors, and amenities.
- **A sitemap:** Homepage, About, Spaces (or Membership Plans), Blog, Contact. Add Events, FAQ, and others later.
- **Written content:** homepage headline and subheading, three or four value propositions, About copy, plan descriptions with approximate prices, consistent calls to action, and contact details. Drafts are fine.
- **Design inspiration:** five to ten sites with layouts, spacing, typography, and color you like, as a reference rather than something to copy.
- **Organization:** keep `/brand`, `/images`, `/content`, and `/reference` folders together.

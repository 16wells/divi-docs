# The Divi Email Optin Module

!!! abstract "Quick Reference"
    **What it is:** A signup form that sends subscribers to your email provider (21 supported).
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Email Optin** from the module list (or search for it).
    **Key settings:** Email Account, Fields, Success Action, Spam Protection, Privacy.

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Email Optin module.

## Use cases

- **Lead magnets:** trade an eBook or whitepaper for an email address.
- **Inline post opt-ins:** place a form inside a blog post, next to content the reader already cares about.
- **Slide-out forms:** combine with scroll effects to reveal a form as visitors scroll.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Set the form text, connect your email provider, and choose the fields and success behavior.

| Setting | Description |
|---|---|
| [Text](../options-groups/text.md) | Title, button, body, and footer text. |
| Email Account | The email provider and the subscriber list. |
| [Fields](../builder/understanding-the-fields-option-group-in-divi-5.md) | Which form fields are visible. |
| Success Action | Show a success message or redirect to another URL. |
| [Spam Protection](../options-groups/spam-protection.md) | Enables Google reCAPTCHA. |
| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Elements](../options-groups/elements.md) | Adds nested modules, such as the Link module. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| [Loop](../builder/loop-builder.md) | Turns on the Loop Builder. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

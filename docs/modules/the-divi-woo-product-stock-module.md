# The Divi Woo Product Stock Module

!!! abstract "Quick Reference"
    **What it is:** Shows a product's availability (in stock or out of stock) and, when stock management is on, the exact quantity.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Use it in product templates or any layout, targeting **This Product** or a specific product.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Stock**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Product templates:** place stock status beside the Add to Cart button.
- **Limited-run promos:** show remaining quantity to encourage faster purchases.
- **Featured product callouts:** show a fixed product's stock in a homepage or sidebar promo.

# The Divi Woo Product Rating Module

!!! abstract "Quick Reference"
    **What it is:** Shows a product's average star rating based on customer reviews.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Place and style the rating anywhere to surface social proof and build trust.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Rating**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Custom product templates:** add the rating under the title on every product page.
- **Sales or landing pages:** pair ratings with testimonials and calls to action.
- **Category or archive pages:** show ratings after product images so shoppers can compare quickly.

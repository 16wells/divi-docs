# The Divi Tabs Module

!!! abstract "Quick Reference"
    **What it is:** A module that groups text, images, and other content into clickable tabs.
    **Add it:** Gray Plus icon inside a Row, then pick Tabs from the module list (or search for it).
    **Settings:** Content, Design, and Advanced tabs.

The Tabs module lets visitors switch between panels of content without leaving the spot on the page. Tabs sit in a horizontal row at larger sizes and stack when the module is placed in a narrow (quarter-width) column.

## Add the Tabs module

1. When you open the Visual Builder, Divi starts you with a Section.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row to open the module list.
4. Select **Tabs**, or type its name into the search field.

## Use cases

- **Product features:** put each feature or spec set in its own tab so visitors can compare quickly.
- **FAQs:** group questions by topic, one tab per topic.
- **Services or pricing:** separate plans or service categories, such as business, personal, and enterprise.

## Add, edit, duplicate, and delete tab items

1. Open the Tabs settings by clicking the module or its Gear icon.
2. **Edit:** click the Pencil icon beside the tab item to change it.
3. **Add:** in the Content tab, click **Add New Tab Item**, fill in the details, then use the arrow at the top left to go back to the main settings.
4. **Duplicate:** click the Duplicate icon on the tab item.
5. **Delete:** click the Trash icon on the tab item.

## Save your work

Press Cmd + S (Mac) or Ctrl + S (Windows), or use the Save button in the Visual Builder, then Exit when you are done.

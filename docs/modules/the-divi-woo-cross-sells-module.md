# The Divi Woo Cross Sells Module

!!! abstract "Quick Reference"
    **What it is:** Displays the products you have linked as cross-sells in WooCommerce.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Cross-sells are complementary or add-on products, usually shown on the cart page. In Divi 5 you can place this module anywhere in a cart layout and style it to match your store.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Cross Sells**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Cart page promotions:** show cross-sells under the cart items so shoppers can add accessories before checkout.
- **Checkout sidebars:** keep add-ons visible in a sidebar while shoppers review their cart.
- **Seasonal campaigns:** feature cross-sells tied to a promotion, such as holiday bundles, to raise order value.

# Using Divi Position Options

!!! abstract "Quick Reference"
    **What it is:** The Position option group, which controls how a module is placed in the page layout.
    **Where it lives:** Module settings, Advanced tab, Position.
    **Key settings:** Position, Vertical Offset, Horizontal Offset, Z-index.

For the full option-group reference, see [Position Options](../options-groups/position.md).

## Open the options

1. Click the module's gear icon, or the module itself, to open its settings.
2. Go to the **Advanced** tab and find the **Position** option group.

## Settings

| Setting | Description |
|---|---|
| Position | **Relative** (default) keeps the module in normal flow and applies offsets from its own spot without moving neighbors. **Absolute** removes it from the flow and positions it against its closest positioned ancestor or the viewport. **Fixed** removes it from the flow and keeps it in place in the viewport while scrolling. |
| Vertical Offset | Moves the module up or down. Positive values move it down; negative values move it up. |
| Horizontal Offset | Moves the module sideways. Positive values move it right; negative values move it left. |
| Z-index | Stacking order. Higher values sit above lower ones. |

## Tips

- Use **Fixed** for sticky items such as navigation bars or promotional calls to action.
- Raise the **Z-index** to keep important content, like text, above backgrounds.
- Check positioning on every device to avoid overlaps or misalignment.

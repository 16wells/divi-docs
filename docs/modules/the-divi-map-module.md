# The Divi Map Module

!!! abstract "Quick Reference"
    **What it is:** An interactive Google map that can carry several pin locations.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Map** from the module list (or search for it).
    **Key settings:** Add New Pin, Map (needs a Google Maps API key), Controls.

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Map module.

## Use cases

- **Business locations:** mark store or office addresses so customers can find you.
- **Event venues:** show attendees where a conference or gathering takes place.
- **Multi-location overviews:** pin several branches, partners, or landmarks on one map.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Add pins and choose the map location.

| Setting | Description |
|---|---|
| Add New Pin | Adds one or more pins to the map. |
| Map | Sets the map location. To display any location you first need a Google Cloud project with billing enabled and a Google Maps API key. |
| [Link](../options-groups/link.md) | Makes the whole module clickable. |
| [Background](../options-groups/background.md) | Background styles for the Map module. |
| [Loop](../builder/loop-builder.md) | Turns on the Loop Builder. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

## Managing map pins

1. Click the module, or its Gear icon, to open the module settings.
2. To edit a pin, click the Gear icon next to it.
3. To add a pin, click **Add New Pin** in the Content tab, enter the title and body content, then use the arrow at the top left to go back.
4. To remove a pin, click the Trash icon next to it.

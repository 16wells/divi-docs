# The Divi Woo Product Reviews Module

!!! abstract "Quick Reference"
    **What it is:** Shows a product's reviews plus the built-in review form (star rating and text field).
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Place and style reviews in custom product templates, landing pages, or any other layout.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Reviews**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Below product details:** show reviews under the description with the form visible to encourage submissions.
- **Landing page social proof:** put reviews and the form beside calls to action.
- **Tabless product layouts:** replace default tabs with a dedicated reviews section.

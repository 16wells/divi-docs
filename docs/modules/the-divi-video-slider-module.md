# The Divi Video Slider Module

!!! abstract "Quick Reference"
    **What it is:** A module that groups several videos into one slider that visitors can switch between.
    **Add it:** Gray Plus icon inside a Row, then pick Video Slider from the module list (or search for it).
    **Settings:** Content, Design, and Advanced tabs.

The Video Slider shows a main video along with a set of other videos the visitor can switch between. Videos can be uploaded to WordPress or embedded from YouTube or Vimeo.

## Add the Video Slider module

1. When you open the Visual Builder, Divi starts you with a Section.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row to open the module list.
4. Select **Video Slider**, or type its name into the search field.

## Use cases

- **Product lines:** highlight different products or features in a single browsable strip.
- **Video portfolios:** feature films, animations, or ads together.
- **Event highlights:** combine keynotes, behind-the-scenes clips, and attendee testimonials.

## Settings

The module settings open as soon as you add the module. They are split into three tabs.

### Content tab

Manage the videos in the slider, slider elements, and the overlay for the main video.

| Setting | Description |
|---|---|
| Content | Add or remove the videos in the slider. |
| Elements | Show or hide navigation arrows and set how the slider controls behave. |
| Overlay | Show an overlay image on the main video. |
| [Background](../options-groups/background.md) | Background color, gradient, image, video, pattern, or mask. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position of the module inside a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | The module's label and whether it stays visible inside the Visual Builder. |

## Add, edit, duplicate, and delete videos

1. Open the Video Slider settings by clicking the module or its Gear icon.
2. **Edit:** click the Pencil icon beside the video to change it.
3. **Add:** in the Content tab, click **Add New Video**, fill in the details, then use the arrow at the top left to go back to the main settings.
4. **Duplicate:** click the Duplicate icon on the video.
5. **Delete:** click the Trash icon on the video.

## Save your work

Press Cmd + S (Mac) or Ctrl + S (Windows), or use the Save button in the Visual Builder, then Exit when you are done.

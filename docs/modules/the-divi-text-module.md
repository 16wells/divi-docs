# The Divi Text Module

!!! abstract "Quick Reference"
    **What it is:** The general-purpose module for headings, paragraphs, lists, and other formatted text.
    **Add it:** Gray Plus icon inside a Row, then pick Text from the module list (or search for it).
    **Settings:** Content, Design, and Advanced tabs.

The Text module is the workhorse for written content. It works in pages, posts, templates, headers, and footers, and it pairs with other modules and with dynamic content.

## Add the Text module

1. When you open the Visual Builder, Divi starts you with a Section.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row to open the module list.
4. Select **Text**, or type its name into the search field.

## Use cases

- **Custom content blocks:** write and format paragraphs, headings, and lists for posts, service descriptions, or product details.
- **Inline calls to action:** add persuasive text with links for newsletter signups, downloads, or contact prompts.
- **Captions and context:** place descriptive text beside images, video, or graphics.

## Settings

The module settings open as soon as you add the module. They are split into three tabs.

### Content tab

The text itself, plus the standard module options.

| Setting | Description |
|---|---|
| Text | The module's text content. |
| [Link](../options-groups/link.md) | Make the whole module clickable and send visitors to a page, section, or external URL. |
| [Background](../options-groups/background.md) | Background color, gradient, image, video, pattern, or mask. |
| [Loop](../builder/loop-builder.md) | Turn on the loop builder so the module repeats for each item in a query. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position of the module inside a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | The module's label and whether it stays visible inside the Visual Builder. |

### Design tab

Visual styling for the Text module.

| Setting | Description |
|---|---|
| [Layout](../builder/understanding-divi-s-new-flexbox-layout.md) | Display style: Block, Flex (default), or Grid. Grid is covered in [CSS grid layout](../builder/understanding-divi-s-css-grid-layout.md). |
| [Text](../options-groups/text.md) | Text styles that apply across the whole module. |
| [Heading Text](../options-groups/heading-text.md) | Styling for headings in the content. |
| [Body Text](../options-groups/body-text.md) | Styling for body copy. |
| [Sizing](using-divi-sizing-options.md) | Width, height, and alignment of the Text module. |
| [Spacing](using-divi-spacing-options.md) | Margin and padding around and inside the module. |
| [Border](using-divi-border-options.md) | Border width, color, style, and rounded corners. |
| [Box Shadow](using-divi-box-shadow-options.md) | Shadow around the module. |
| [Filters](using-divi-filter-and-blend-mode-options.md) | Hue, saturation, and other filters plus blend modes. |
| [Transform](using-divi-transform-options.md) | Scale, rotate, skew, and translate the module. |
| [Animation](using-divi-animation-options.md) | Entrance animation styles. |

### Advanced tab

Tools for CSS, visibility, positioning, and behavior.

| Setting | Description |
|---|---|
| [Attributes](../options-groups/attributes.md) | Add a CSS ID, reusable CSS classes, or custom HTML attributes. |
| [CSS](../options-groups/css.md) | Write custom CSS for the Text module. |
| [HTML](../builder/semantic-elements.md) | Pick the semantic HTML tag the module outputs. |
| [Conditions](../options-groups/conditions.md) | Show or hide the module depending on rules you define. |
| [Interactions](../builder/interactions.md) | Trigger actions on the module, such as showing or hiding it. |
| [Visibility](../options-groups/visibility.md) | Control which device sizes display the module. |
| [Transitions](../options-groups/transitions.md) | Set how long hover and state changes take. |
| [Position](../options-groups/position.md) | Control how the module is placed on the page. |
| [Scroll Effects](../options-groups/scroll-effects.md) | Change how the module behaves while the page scrolls. |

## Save your work

Press Cmd + S (Mac) or Ctrl + S (Windows), or use the Save button in the Visual Builder, then Exit when you are done.

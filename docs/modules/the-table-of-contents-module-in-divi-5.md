# The Table of Contents module in Divi 5

!!! abstract "Quick Reference"
    **What it does:** Scans the headings already on the page and turns them into a navigable list of links.
    **Best for:** Long posts, guides, documentation, and knowledge base pages.
    **Add it:** Row, Gray Plus icon, find **Table of Contents** (or use module search).
    **Tip:** Use proper heading levels (for example via the Heading module) so the list nests cleanly.

## Use cases

- **Long-form posts and guides:** an overview readers can jump from.
- **Documentation and knowledge base pages:** navigation through dense reference content.
- **Sticky on-page navigation:** pair the module with sticky positioning so the list stays visible while scrolling.

## Settings

### Content tab

| Setting | Description |
|---|---|
| Content | Choose what the table is built from, including which page headings it pulls in. |
| Link | Make the whole module clickable. |
| Elements | Add other Divi 5 modules as nested elements. |
| Background | Color, gradient, image, or video background. |
| Loop | Repeat the module across dynamic content with the Loop Builder. |
| Order | Position within a Flexbox or Grid layout. |

### Design tab

| Setting | Description |
|---|---|
| Scroll | Scroll behavior, such as smooth-scrolling to a heading on click and highlighting the section in view. |
| Layout | Flexbox or CSS Grid arrangement of the list. |
| Title Text | Font, size, color, and spacing of the table's title. |
| List Text | Base text style for every entry. |
| List Level 1 to 6 Text | Per-heading-level overrides so each level can look distinct. |
| Marker Text | Style of the bullet or number beside each item. |
| Empty State Text | Style of the message shown when the page has no headings to list. |
| Sizing, Spacing, Border, Box Shadow, Filters, Transform, Animation | Standard design option groups. |

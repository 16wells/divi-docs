# The Divi Woo Checkout Billing Module

!!! abstract "Quick Reference"
    **What it is:** The billing address form fields used at WooCommerce checkout.
    **Where it lives:** WooCommerce folder in the module library; intended for a Theme Builder checkout template.
    **Key setting:** Layout: Default, Fullwidth or 2 Columns.

!!! note
    WooCommerce must be installed and active before the Woo Checkout Billing module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Checkout Billing** to insert it, or find it with the search box.

## Use cases

1. **Brand-styled checkout:** Replace the default billing section with a form that has your fonts, backgrounds and fullwidth layout.
2. **Compact multi-column form:** Use the 2 Columns layout to place fields side by side and cut vertical scrolling.
3. **Prominent form notices:** Style error messages, such as a missing billing address, so they are hard to miss.

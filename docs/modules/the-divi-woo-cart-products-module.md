# The Divi Woo Cart Products Module

!!! abstract "Quick Reference"
    **What it is:** A styleable list of the products currently in the cart, with names, images, prices, quantities and totals.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Elements toggles: product image, coupon code, update cart button, remove icon.

!!! note
    WooCommerce must be installed and active before the Woo Cart Products module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Cart Products** to insert it, or find it with the search box.

## Use cases

1. **Custom cart pages:** Replace the default WooCommerce cart with a layout that matches your brand.
2. **Sidebar mini-cart:** Place it in a global sidebar so shoppers see their selection while browsing.
3. **Landing pages with a cart summary:** Remind shoppers what they have added on promotional or upsell pages.

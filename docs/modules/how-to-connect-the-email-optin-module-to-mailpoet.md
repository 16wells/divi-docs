# How to Connect the Email Optin Module to MailPoet

!!! abstract "Quick Reference"
    **What it is:** The steps for linking the Divi 5 [Email Optin module](the-divi-email-optin-module.md) to MailPoet so form submissions land in your chosen list.
    **Where to set it:** Email Optin module settings → Content tab → Email Account.
    **You need:** The MailPoet plugin installed, activated, and set up, and a MailPoet list.

## Install and set up MailPoet

1. In your WordPress dashboard, go to **Plugins → Add Plugin**.
2. Search for **MailPoet – Newsletters, Email Marketing, and Automation**, then click **Install Now** and **Activate**.
3. Click **Begin Setup** to start the plugin's configuration.
4. Connect the plugin to your MailPoet account. In the account's **My Subscriptions** tab, copy the key.
5. Paste it into **Activation Key** on the plugin page and click **Verify Account**.
6. Click **Start using MailPoet**.


## Connect the module

1. Open the Email Optin module's settings by clicking the module or its **Gear icon**.
2. Go to **Content tab → Email Account**.
3. Choose **MailPoet** from the provider list and click **Add**.
4. Enter an **Account Name** (for example `my-mailpoet`); any label works.
5. Click **Submit**.
6. Choose the MailPoet list you want to use.

## Gotchas

- Finish MailPoet's own setup (activation key verified) before adding it in the module.
- The source intro says submissions go to a "Brevo" list; that is a copy error. They go to the MailPoet list you pick.

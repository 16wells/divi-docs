# How to Recover Missing or Deleted Content on a Page

!!! abstract "Quick Reference"
    **When to use:** A page's content or layout vanished after Publish or Update (rare).
    **Try in order:** WordPress Revisions, then Divi's History panel (only if the Builder tab is still open), then a hosting backup.

## Option 1: WordPress Revisions

1. Go to **WordPress Dashboard → Pages → All Pages**.
2. Edit the affected page.
3. In the right sidebar, click the **Revisions** link.
4. Move through the timeline with **Previous/Next** to find a good version.
5. Click **Restore This Revision**.

The comparison view shows removed items in the left (red) column and added items in the right (green) column.

## Option 2: Divi's History panel

This works only if the browser tab with the Visual Builder has not been closed since the content was lost.

1. Click the **Gear icon** (top right).
2. Choose **History**.
3. Pick the restore point to return to.

## Option 3: Hosting backup

If neither method helps, ask your host to roll back to an available backup.

- Use a backup no older than about a day (24 hours).
- Restoring wipes everything done on the site after the backup date.

## Gotchas

- Do not close the Builder tab while diagnosing; it is your only route to the History panel.
- A host rollback affects the whole site, so treat it as the last resort.

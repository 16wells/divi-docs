# The Divi Woo Product Upsell Module

!!! abstract "Quick Reference"
    **What it is:** Shows upsell products linked in WooCommerce's Linked Products for a chosen product.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Content group: product, count, columns, order and offset.

!!! note
    WooCommerce must be installed and active before the Woo Product Upsell module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Product Upsell** to insert it, or find it with the search box.

### Link upsell products first

1. Go to **WordPress Dashboard > Products** and edit a product.
2. Open the **Linked Products** tab.
3. In the **Upsells** box, enter the products to link.

Use the **This Product** option on product templates, or pick a specific product on any page, including cart and checkout.

## Use cases

1. **Custom product templates:** Show linked upsells on every product page built from a template.
2. **Cart and checkout pages:** Offer a specific product's upsells before the order is placed.
3. **Sales and landing pages:** Feature related higher-value items beside promotional content.

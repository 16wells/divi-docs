# How to Access Your Divi Cloud in Divi 5

!!! abstract "Quick Reference"
    **What it is:** Divi Cloud makes your saved layouts, sections, rows, modules, and code snippets available on any Divi 5 site you work on.
    **Where to sign in:** Visual Builder > **Add Layout** icon > **Load From Library** modal > **Sign In To Divi Cloud** button (top right).
    **Session length:** Sign-in lasts 30 days.

## Sign in to Divi Cloud

1. Open a page in the **Visual Builder**.
2. Click the **Add Layout** icon in the left sidebar. The Load From Library modal opens.
3. Click the **Premade Layout** or **Saved Layout** card.
4. Click **Sign In To Divi Cloud** in the top right corner of the modal.
5. Enter your Elegant Themes account credentials in the pop-up login window.

Once signed in, your Cloud items appear next to your local Divi Library items. The session stays active for 30 days, so you do not need to log in each time you open the builder.

!!! tip
    If the **Sign In To Divi Cloud** button is missing, update Divi to the latest version.

## Filter between local and Cloud items

The **Locations** filter in the modal's sidebar controls which items are listed.

| Option | Result |
|---|---|
| **This Website** | Only items saved locally to the current Divi site |
| **My Divi Cloud** | Only items saved to your Divi Cloud |
| Both checked, or both unchecked | Everything |

!!! note
    Search and filtering in the modal depend on where you opened it. If you opened it from **Add Section**, only saved sections are shown, even if your Cloud holds layouts, rows, and modules. Open it from the **Add Layout** icon to see all item types.

# The Divi Accordion Module

!!! abstract "Quick Reference"
    **What it is:** Collapsible toggles that keep only one item open at a time, unlike the Toggle module.
    **Where it lives:** Add it from the module library (Gray Plus icon inside a Row) or search for it by name.
    **Key settings:** Accordion items, Toggle Icon, open and closed toggle colors, Title and Body text.

## Add the module

1. In the Visual Builder, click the **Green Plus** icon to add a Row to the Section.
2. Click the **Gray Plus** icon inside the Row to open the module library.
3. Find the **Accordion** module and click it, or use the search box.

## Use cases

- **FAQ section:** Group questions with expandable answers for a tidy, scannable layout.
- **Product or service details:** Show features or tiers compactly and reveal more on demand.
- **Step-by-step instructions:** Break a guide or process into collapsible steps.

## Settings

### Content tab

Manage the accordion items and choose the toggle icon, link, and background.

| Setting | Description |
|---|---|
| Add, Edit, and Remove | Create, change, or delete accordion items (see below). |
| Toggle Icon | The icon shown on each toggle. |
| Link | Turns the whole Accordion module into a link to a page, section, or external URL. |
| Background | Background color, gradient, image, video, pattern, or mask for the Accordion module. |
| Loop | Switches on the [Loop](../builder/loop-builder.md) so the module repeats for each item in a query. |
| Order | Sets where the module sits in a [Flexbox](../builder/understanding-divi-s-new-flexbox-layout.md) or Grid layout. |
| Meta | A custom label for the module and an option to force its visibility inside the Visual Builder. |

### Design tab

Design options for the Accordion module.

| Setting | Description |
|---|---|
| Layout | How child elements are arranged: Block, Flex (default), Grid. |
| Icon | Icon design options. |
| Toggle | Background colors for open and closed toggles. |
| Text | Overall text styles. |
| Title Text | Styles for toggle titles. |
| Closed Title Text | Title styles for toggles that are closed. |
| Body Text | Styles for the content inside each toggle. |
| Sizing | Width, height, and related sizing for the Accordion module. |
| Spacing | Margin and padding around and inside the module. |
| Border | Border and corner styling. |
| Box Shadow | Drop shadow styling. |
| Filters | Hue, saturation, brightness, and blend-mode adjustments. |
| Transform | Scale, rotate, skew, and translate effects. |
| Animation | Entrance animation styles. |

### Advanced tab

Options for fine control over markup, visibility, and behavior.

| Setting | Description |
|---|---|
| Attributes | A CSS ID, reusable CSS classes, or custom HTML attributes, handy for hooking into your child theme's stylesheet or custom CSS. |
| CSS | Custom CSS for fine-tuning the Accordion module. |
| HTML | Picks the [semantic HTML tag](../builder/semantic-elements.md) the module outputs. |
| Conditions | Shows or hides the module based on rules, so different visitors see different content. |
| Interactions | Custom [Interactions](../builder/interactions.md), such as showing or hiding the module on a trigger. |
| Visibility | Hides the module on selected device sizes. |
| Transitions | Duration and timing of hover and state transitions. |
| Position | Precise placement of the module on the page. |
| Scroll Effects | How the module moves or changes as the visitor scrolls. |

## Add, edit, and remove accordion items

1. Open the module settings (click the module or its Gear icon).
2. **Edit:** click the Pencil icon beside an item to change its title, body, or design settings.
3. **Add:** in the **Content** tab, click **Add New Accordion Item**, fill it in, then use the arrow at the top left to go back to the main module settings.
4. **Duplicate:** click the Duplicate icon beside the item.
5. **Remove:** click the Trash icon beside the item.

Design changes made on the module apply to every accordion item. To style one accordion item on its own, click the Gear icon beside it and use its own Content and Design settings; return with the arrow at the top left.

## Save your work

Press `Cmd + S` (Mac) or `Ctrl + S` (Windows), or use the **Save** and **Exit** buttons in the Visual Builder.

## Settings & Options

### General

| Setting | Type | Description |
|---------|------|-------------|
| Support Chat History |  | Your past support chat history associated with your old username will no longer be accessible. |
| Divi Cloud Items |  | Items saved in Divi Cloud cannot be transferred to the new username. To retain them, export your items before the change and re-import them afterward. |
| Additional Subscriptions |  | Non-transferable subscriptions such as Divi AI, Cloud, VIP, Teams, or Marketplace licenses linked to your old username will no longer be accessible.​Tip: If you’re unsure about active subscriptions, we can help you verify this. |
| Full Divi Access |  | You’ll retain access to Divi support, unlimited downloads of Divi and other Elegant Themes plugins, future updates, and the latest features and layout packs. |
| Update Your Username and API Key |  | Once the change is made, you’ll need to update your Divi username and API key on all WordPress sites using Divi. |
| Check for Divi Dash Connections |  | If any of your websites or clients are connected to Divi Dash, please confirm with us. Additional instructions will be provided before making the username change. |

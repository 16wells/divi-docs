# The Divi Woo Product Gallery Module

!!! abstract "Quick Reference"
    **What it is:** A product image gallery you can place and style freely.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Design tab Layout: Slider or Grid.

!!! note
    WooCommerce must be installed and active before the Woo Product Gallery module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Product Gallery** to insert it, or find it with the search box.

## Use cases

1. **Custom product templates:** Show all product images in a consistent design within a dedicated template section.
2. **Landing pages:** Put the gallery next to promotional text or calls to action.
3. **Image-focused layouts:** Use large gallery visuals as the main element of a minimal design.

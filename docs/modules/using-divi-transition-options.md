# Using Divi Transition Options

!!! abstract "Quick Reference"
    **What it is:** The Transitions option group, which sets the timing and speed of hover animations on a module.
    **Where it lives:** Module settings, Advanced tab, Transitions.
    **Key settings:** Transition Duration, Transition Delay, Transition Speed Curve.

For the full option-group reference, see [Transitions Options](../options-groups/transitions.md).

## Open the options

1. Click the module's gear icon, or the module itself, to open its settings.
2. Go to the **Advanced** tab and find the **Transitions** option group.

## Settings

| Setting | Description |
|---|---|
| Transition Duration | Time, in milliseconds, for the transition to complete. For example, 300ms is smooth and 100ms is quick. |
| Transition Delay | Time, in milliseconds, before the transition starts. A short delay such as 200ms can make a hover feel intentional. |
| Transition Speed Curve | Easing: Ease (natural), Linear (constant), Ease-In (slow start), Ease-Out (slow finish), or Ease-In-Out (slow start and finish). |

## Tips

- Moderate durations, roughly 300 to 500ms, usually feel natural and polished.
- Avoid long delays, which make hover effects feel unresponsive.
- Test on desktop and touch devices.

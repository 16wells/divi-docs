# The Divi Woo Notice Module

!!! abstract "Quick Reference"
    **What it is:** Shows WooCommerce notifications, for example that a product was added to the cart.
    **Where it lives:** WooCommerce folder in the module library; works on product, cart and checkout pages and in Theme Builder templates.
    **Key setting:** Content group: page type and product.

!!! note
    WooCommerce must be installed and active before the Woo Notice module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Notice** to insert it, or find it with the search box.

## Use cases

1. **Cart update confirmation:** Show a branded message after a product is added or removed.
2. **Checkout error messages:** Display errors such as missing fields or invalid coupons clearly.
3. **Coupon feedback:** Confirm that a coupon was applied with a success message that stands out.

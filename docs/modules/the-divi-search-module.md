# The Divi Search Module

!!! abstract "Quick Reference"
    **What it is:** A search bar you can place in headers, footers, pages, and posts.
    **Where it lives:** Click the Gray Plus icon inside a Row, then pick **Search** from the module list (or search for it).
    **Key settings:** Text (placeholder), Elements (search button), Exceptions.

## Add the module

1. Open the Visual Builder; Divi adds a Section automatically.
2. Click the Green Plus icon to insert a Row.
3. Click the Gray Plus icon inside the Row and choose the Search module.

## Use cases

- **Site-wide search:** put the bar in the header or footer.
- **Scoped search:** exclude content so results stay relevant, such as keeping only posts, projects, or products.
- **Large sites:** help visitors navigate stores and knowledge bases.

## Settings

The module settings open as soon as the module is added, organized into Content, Design, and Advanced tabs.

### Content tab

Set the placeholder text, the button, and what to leave out of results.

| Setting | Description |
|---|---|
| [Text](../options-groups/text.md) | Placeholder text for the input field. |
| [Elements](../options-groups/elements.md) | Shows or removes the search button. |
| Exceptions | Excludes Pages, Posts, or posts from chosen categories from results. |
| [Background](../options-groups/background.md) | Background styles for the module. |
| [Order](../builder/understanding-divi-s-new-flexbox-layout.md) | Position within a Flexbox or Grid layout. |
| [Meta](../options-groups/meta.md) | Module label and Visual Builder visibility override. |

# The Divi Woo Product Title Module

!!! abstract "Quick Reference"
    **What it is:** Dynamically shows a product's title, for the current product or any specific product.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Place it in product templates, landing pages, or regular page builds.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Title**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Consistent product templates:** add it at the top so every product name appears in the same style.
- **Custom landing pages:** put the title above pricing, images, or calls to action.
- **Featured products:** show a specific product's title in homepage sections or campaign banners.

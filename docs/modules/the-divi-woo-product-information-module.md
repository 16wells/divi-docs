# The Divi Woo Product Information Module

!!! abstract "Quick Reference"
    **What it is:** Displays details from WooCommerce's Additional Information panel, such as dimensions, weight, and attributes.
    **Where it lives:** Gray Plus icon in a Row, then the WooCommerce folder (or use search).
    **Requires:** WooCommerce installed and activated.

Target **This Product** or a specific product, show or hide the title, make the module a link, and style the attribute table with Divi's design controls.

## Add the module

1. Click the **Green Plus** icon to add a Row.
2. Click the **Gray Plus** icon inside the Row to open the module list.
3. Open the **WooCommerce** folder and select **Woo Product Information**, or search for it.

See [Divi WooCommerce Modules](divi-woocommerce-modules.md) for the full set of Woo modules.

## Use cases

- **Custom product templates:** place specifications below the description in a consistent design.
- **Comparison pages:** repeat the module across products in a grid so shoppers can compare attributes.
- **Shipping or promo sections:** surface dimensions or fit details in promotional layouts.

# The Divi Woo Product Tabs Module

!!! abstract "Quick Reference"
    **What it is:** The default WooCommerce product tabs, placeable and styleable anywhere in a product layout.
    **Where it lives:** WooCommerce folder in the module library.
    **Key setting:** Included Tabs choose which WooCommerce tabs appear.

!!! note
    WooCommerce must be installed and active before the Woo Product Tabs module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Product Tabs** to insert it, or find it with the search box.

## Use cases

1. **Custom product templates:** Keep the familiar Description, Reviews and Additional Information tabs with your own styling.
2. **Landing pages:** Organize specs and customer feedback in a clean, scannable layout.
3. **Single-page stores:** Separate details, reviews and FAQs on a long product page.

# The Divi Woo Checkout Shipping Module

!!! abstract "Quick Reference"
    **What it is:** The shipping address form from WooCommerce checkout.
    **Where it lives:** WooCommerce folder in the module library; intended for a Theme Builder checkout template.
    **Key setting:** Layout: Default, Fullwidth or 2 Columns.

!!! note
    WooCommerce must be installed and active before the Woo Checkout Shipping module appears in the module list.

## Add the module

1. Click the green **+** icon to add a Row.
2. Click the gray **+** icon inside the Row to open the module library.
3. Open the **WooCommerce** folder.
4. Click **Woo Checkout Shipping** to insert it, or find it with the search box.

## Use cases

1. **Relocated shipping form:** Place the shipping section wherever your checkout design needs it.
2. **Compact layouts:** Use the 2 Columns layout to shorten the form.
3. **Brand consistency:** Style labels, inputs, backgrounds and spacing to match your store.

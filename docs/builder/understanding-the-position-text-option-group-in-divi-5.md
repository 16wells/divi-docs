# Understanding the Position Text Option Group in Divi 5

!!! abstract "Quick Reference"
    **What it is:** A Design-tab option group that styles the position text in modules such as Person.
    **Where to find it:** Open the Person module settings, go to the **Design** tab, and find **Position Text**.
    **Key behavior:** Size, color, line height, and letter spacing also accept [Global Variables](global-variables.md).

## Where to find it

1. Open the settings of the Person module (click its gear icon or the module itself).
2. Go to the **Design** tab.
3. Locate the **Position Text** option group.

## Settings

| Setting | Description |
|---|---|
| Position Font | Pick a font from the dropdown or upload a custom one. |
| Position Font Weight | Boldness of the text, from light to extra-bold. |
| Variable Font Options | Shown only when the chosen font is a Google variable font (the source names Google Sans Flex and Bitcount as examples). Axes include Weight, Optical Sizing, Width, Slant, Crsv, Element Shape, Element Expansion, Rond, and Grade. |
| Position Text Size | Font size, set with the slider or a typed value. Accepts Global Variables. |
| Position Text Color | Text color. Accepts Global Variables. |
| Position Line Height | Space between lines of text. Accepts Global Variables. |
| Position Letter Spacing | Space between letters. Accepts Global Variables. |
| Position Text Alignment | Left, center, right, or justified. |
| Position Capitalization | Uppercase, Capitalize, Lowercase, Smallcaps (lowercase letters shown as smaller capitals), or All Small Caps (every letter shown as a small cap, including existing capitals). |
| Position Font Style | Italic, Underline, Overline, and Strikethrough. When any line style is on, you can also set Line Color (accepts Global Variables), Line Thickness, and Line Type (Solid, Double, Dotted, Dashed, or Wavy). |
| Position Line Wrap Style | Default keeps the browser's native wrapping; Balanced breaks short text into lines of more even length; Pretty wraps text to avoid awkward endings. |
| Position Text Direction | Standard Horizontal, Vertical (right to left), or Vertical (left to right). The vertical modes stack characters top to bottom or bottom to top, with new lines starting to the left of the previous one. |
| Position Hyphenation | When on, the browser may break a word that is too long for the line and add a hyphen. |
| Position Fill Type | None, Gradient, Image, or Transparent fill for the text itself. |
| Position Stroke Width / Stroke Color | Thickness and color of an outline around the letters. |
| Position Columns | Number of columns the text flows through. |
| Position Text Shadow | Adds a shadow with Direction (horizontal and vertical offset), Blur, and Color. |

## Tips

- Keep font sizes and line heights readable, especially on mobile.
- Match the text color and style to the rest of the design.
- Use shadows sparingly; strong effects hurt readability.

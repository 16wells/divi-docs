# Understanding the Carousel Item Title Text Option Group in Divi 5

!!! abstract "Quick Reference"
    **What it is:** The design option group that styles the carousel item title text in modules such as [Post Carousel](../modules/post-carousel.md).
    **Where to find it:** Open the Post Carousel module settings, go to the **Design** tab, and find **Carousel Item Title Text**.
    **Key behavior:** Size, color, line height, and letter spacing accept Global Variables. Variable font controls appear only for variable fonts.

## Where to find it

1. Open the Post Carousel module settings by clicking the gear icon or the module itself.
2. Switch to the **Design** tab.
3. Locate the **Carousel Item Title Text** option group.

## Settings

| Setting | Description |
|---|---|
| Carousel Item Title Heading Level | Heading tag (H1-H6) used for the text, which sets its place in the page's HTML structure. |
| Carousel Item Title Font | Pick a font from the dropdown or upload a custom one. |
| Carousel Item Title Font Weight | Boldness of the text, from light to extra-bold. |
| Variable font settings | Shown only when a Google variable font is selected. See the variable font options below. |
| Carousel Item Title Text Size | Font size, via slider or typed value. Accepts Global Variables. |
| Carousel Item Title Text Color | Color of the text. Accepts Global Variables. |
| Carousel Item Title Line Height | Space between lines of text. Accepts Global Variables. |
| Carousel Item Title Letter Spacing | Space between letters, via slider or typed value. Accepts Global Variables. |
| Carousel Item Title Text Alignment | Left, center, right, or justified. |
| Carousel Item Title Capitalization | Text case: Uppercase, Capitalize, Lowercase, Smallcaps, or All Small Caps. |
| Carousel Item Title Font Style | Italic, Underline, Overline, and Strikethrough toggles. See line options below. |
| Carousel Item Title Line Wrap Style | How text breaks across lines: Default, Balanced, or Pretty. |
| Carousel Item Title Text Direction | Standard Horizontal or one of two vertical modes. |
| Carousel Item Title Hyphenation | Lets the browser split long words with a hyphen when they do not fit on a line. |
| Carousel Item Title Fill Type | None, Gradient, Image, or Transparent text fill. |
| Carousel Item Title Stroke Width | Thickness of an outline around the text letters, with a stroke color setting. |
| Carousel Item Title Columns | Number of columns the text flows through. |
| Carousel Item Title Text Shadow | Adds a shadow with direction, blur, and color controls. |

## Variable font options

These controls appear only when the selected font is a Google variable font (for example Google Sans Flex or Bitcount). Each one fine-tunes an axis of the font through variable font interpolation:

- **Variable Font Weight:** slider or numeric value.
- **Optical Sizing:** turns on automatic optical size handling.
- **Variable Font Width and Slant:** adjust the width and slant axes.
- **Crsv, Element Shape, Element Expansion, Rond, and Grade:** additional axes, shown when the font supports them.

## Text details

**Capitalization**

- **Uppercase:** every letter is capital.
- **Capitalize:** first letter of each word is capital.
- **Lowercase:** every letter is small.
- **Smallcaps:** lowercase letters render as smaller capitals.
- **All Small Caps:** all letters render as small capitals, including ones that were already capital.

**Font style**

- **Italic** slants the text; **Underline**, **Overline**, and **Strikethrough** add a line below, above, or through it.
- When any line option is on, you can also set **Line Color** (accepts Global Variables), **Line Thickness**, and **Line Type** (Solid, Double, Dotted, Dashed, or Wavy).

**Line wrap style**

- **Default:** native browser wrapping.
- **Balanced:** short text breaks into lines of more even length.
- **Pretty:** wraps in a cleaner way that avoids stray single words at the end.

**Text direction**

- **Standard Horizontal:** reads left to right.
- **Vertical (right to left)** and **Vertical (left to right):** stack the text top to bottom or bottom to top, with each new line starting to the left of the previous one.

**Fill type and stroke**

- **None** leaves the text unfilled, **Gradient** and **Image** fill the letters with that style, and **Transparent** makes the fill clear.
- **Stroke Width** sets the outline thickness; **Title Stroke Color** sets its color.

**Text shadow**

- **Direction:** horizontal and vertical offset.
- **Blur:** how soft or sharp the shadow looks.
- **Color:** the shadow color.

## Tips

- Use bold fonts and enough spacing so the title stays readable over the item image.
- Contrasting colors or a subtle text shadow help the title stand out.
- Match the title style to the rest of the module's fonts and colors.
- Preview on several screen sizes to confirm alignment and readability.

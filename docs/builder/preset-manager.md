# Preset Manager

!!! abstract "Quick Reference"
    **What it is:** A Visual Builder sidebar tool listing every element preset and option group preset on the site, with a preview panel for safe editing.
    **Where to find it:** The Preset Manager icon in the left sidebar, beside the Variable Manager and Style Inspector.
    **Key behavior:** Editing a preset happens in a separate preset editing mode, so page content is untouched until you save.

## What it includes

- **Preset Manager:** a searchable, filterable list of all Element Presets and Option Group Presets.
- **Preset Preview:** a panel that shows a live sample of a preset while you add or edit it, and can show it on different background colors taken from your color variables.

You can work on presets without selecting anything on the page.

## Open it

1. Open any page in the Visual Builder.
2. Click the Preset Manager icon in the left sidebar.

## What you can do

- **Create** element presets and option group presets (Typography, Button, Border, Spacing, and so on).
- **Edit** a preset; changes apply to every element using it.
- **Duplicate** a preset as the start of a variation, such as an outline button.
- **Delete** presets you no longer need.
- **Set a default** element preset for a module or element type so new elements start with it.
- **Reorder** presets by dragging. The order carries over to the preset menus in module settings, so favorites can sit at the top.

## Preset Preview

When you add or edit a preset from the manager, the settings panel edits the preset itself, not a module on the page, and the Preview panel updates in real time. Testing on light and dark backgrounds helps check contrast for buttons, text, and cards.

## Import and export

Presets and variables (colors, fonts, spacing numbers, text, links, images) can be exported and imported.

1. **Export:** click the export icon in the Preset Manager to download a file with the site's presets.
2. **Import:** on another site, open the Preset Manager, click the import icon, and upload the file. The presets are available immediately.

Use it to share a preset library across client sites or reuse your own design system.

## Suggested workflow

1. Build a clear, well-named preset library and refine it in the Preview panel.
2. Sort base presets and common variations (Primary, Secondary, Light/Dark) to the top and remove experiments.
3. Build pages with presets first, before one-off tweaks.
4. To change the site's look, edit the preset in the manager, then check a few key pages.
5. Export presets and variables to start new sites from the same system.

# Understanding the Form Title Text Option Group in Divi 5

!!! abstract "Quick Reference"
    **What it is:** The design options that style the form title text of the Comments module.
    **Where to find it:** Open the module settings (gear icon, or click the module) > **Design** tab > **Form Title Text** option group.
    **Variables:** Size, color, line height, and letter spacing accept [Global Variables](https://help.elegantthemes.com/en/articles/13348842-global-variables-in-divi-5).

## Settings

| Setting | Description |
|---|---|
| Form Title Heading Level | The heading tag for the title: h1 through h6 |
| Form Title Font | Pick a font from the dropdown or upload a custom one |
| Form Title Font Weight | Boldness of the title, from light to extra-bold |
| Form Title Text Size | Font size, set with the slider or a typed value |
| Form Title Text Color | Color of the title text |
| Form Title Line Height | Space between lines of the title |
| Form Title Letter Spacing | Space between letters |
| Form Title Text Alignment | Left, center, right, or justified |
| Form Title Capitalization | Uppercase, Capitalize, Lowercase, Smallcaps, or All Small Caps |
| Form Title Font Style | Italic, Underline, Overline, Strikethrough (see below) |
| Form Title Line Wrap Style | How text wraps: Default, Balanced, or Pretty (see below) |
| Form Title Text Direction | Standard Horizontal, Vertical (right to left), or Vertical (left to right) |
| Form Title Hyphenation | When on, the browser may break an overly long word and add a hyphen |
| Form Title Fill Type | None, Gradient, Image, or Transparent |
| Form Title Stroke Width | Thickness of the text outline; a stroke color setting follows it |
| Form Title Columns | Number of columns the title text flows through |
| Form Title Text Shadow | Adds a shadow with Direction (horizontal and vertical offset), Blur, and Color |

### Capitalization choices

| Option | Result |
|---|---|
| Uppercase | All letters uppercase |
| Capitalize | First letter of each word uppercase |
| Lowercase | All letters lowercase |
| Smallcaps | Lowercase letters shown as smaller capitals |
| All Small Caps | Every letter shown as a small cap, including ones that were uppercase |

### Font style and line options

Font Style offers **Italic**, **Underline**, **Overline**, and **Strikethrough**. When any of the three line styles is enabled, these extra settings appear:

- **Line Color** (accepts Global Variables)
- **Line Thickness**
- **Line Type:** Solid, Double, Dotted, Dashed, or Wavy

### Line wrap styles

- **Default:** native browser wrapping; text moves to a new line when space runs out.
- **Balanced:** breaks short text into lines of more even length.
- **Pretty:** wraps in a way that avoids awkward endings, such as a single word on the last line.

### Text direction

- **Standard Horizontal:** reads left to right across lines.
- **Vertical (right to left):** text runs top to bottom, with each new line starting to the left of the previous one.
- **Vertical (left to right):** text runs bottom to top, with each new line starting to the left of the previous one.

### Variable font options

These controls appear only when the chosen font is a Google variable font (for example Google Sans Flex or Bitcount):

- Variable Font Weight (slider or numeric value)
- Optical Sizing (automatic optical size handling)
- Variable Font Width, Slant, Crsv, Element Shape, Element Expansion, Rond, and Grade (each fine-tuned through variable font interpolation)

## Tips

- Use heading levels consistently so the content hierarchy stays clear.
- Choose fonts, colors, and styles that match the site's branding.
- Tune size, spacing, and line height for readability.
- Use text shadows sparingly so they add contrast without overpowering the design.
